Thought Drawer

개인정보처리방침

시행일: 2026년 10월 28일

Thought Drawer(이하 "앱")는 메모, 사진, 링크를 사용자 본인의 구글 드라이브에 저장하고 정리하는 개인용 노트 앱입니다. 이 방침은 앱이 어떤 정보를 어떻게 다루는지 설명합니다.

1. 운영 방식

앱은 별도의 서버가 없습니다. 사용자의 브라우저가 구글 드라이브와 직접 통신하며, 개발자는 사용자의 노트, 사진, 계정 정보를 받거나 저장하지 않습니다.

2. 다루는 정보

  • 구글 계정 기본 정보(이름, 이메일 주소, 프로필 사진): 로그인한 계정을 화면에 표시하는 데에만 씁니다.
  • 구글 드라이브 파일: 앱은 drive.file 권한만 요청합니다. 이 권한으로는 앱이 직접 만든 파일(드라이브의 「메모」 폴더와 그 안의 노트, 사진)만 읽고 쓸 수 있고, 드라이브의 다른 파일에는 접근할 수 없습니다.
  • 기기 안 저장본: 빠르게 열고 연결이 끊겨도 읽을 수 있도록, 노트 사본과 화면 설정을 사용자 브라우저의 저장 공간(IndexedDB, localStorage)에 보관합니다. 이 저장본은 해당 기기 밖으로 나가지 않으며, 로그아웃하면 지워집니다.

3. 정보를 쓰는 목적

노트를 저장하고, 보여 주고, 검색하고, 폴더로 정리하는 앱 기능을 제공하는 데에만 씁니다. 광고, 분석, 판매, 제3자 제공에 쓰지 않습니다.

4. 사진 속 글자 읽기

사진을 넣으면 글자를 읽기 위해 구글 드라이브의 기본 글자 인식 기능을 사용합니다. 이 과정은 사용자의 드라이브 안에서 이루어지며, 임시로 만든 문서는 바로 지웁니다.

5. 자동 정리(선택)

자동 정리는 사용자가 직접 설정하는 선택 기능입니다. 사용자가 자신의 Claude Code 환경에 자신의 토큰을 넣어 실행하며, 그 환경은 사용자 본인의 계정에서 동작합니다. 개발자는 이 토큰이나 정리 결과를 받지 않습니다. 정리할 때 노트 내용이 사용자의 Claude 계정으로 처리되며, 이는 Anthropic의 정책을 따릅니다.

6. 외부로 나가는 정보

  • 구글(로그인, 드라이브 저장): Google의 개인정보처리방침을 따릅니다.
  • 사용자가 "Claude에게 묻기"를 누를 때에만, 질문과 관련 노트 요약을 담아 claude.ai 새 대화를 엽니다.
  • 글꼴 파일을 jsDelivr, Google Fonts에서 받아 옵니다. 이때 노트 내용은 보내지 않습니다.

7. 보관과 삭제

노트는 사용자의 구글 드라이브에 있으므로 사용자가 직접 지우거나 옮길 수 있습니다. 앱의 접근 권한은 언제든 구글 계정의 서드 파티 연결에서 해제할 수 있습니다. 앱 안에서 로그아웃하면 기기 안 저장본도 지워집니다.

8. 어린이의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않습니다.
