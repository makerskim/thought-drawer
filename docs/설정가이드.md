# Thought Drawer 설정 가이드

처음 한 번만 하면 되는 설정이에요. 전부 무료이고, 30~40분쯤 걸려요.

| 준비물 | 용도 | 비용 |
|---|---|---|
| 구글 계정 | 로그인, 드라이브 저장 | 0원 |
| GitHub 계정 | 앱 주소(웹사이트) 무료 호스팅 | 0원 |
| 지금 쓰는 Claude 구독 (Pro 이상) | 자동 정리 (Claude Code 예약 작업) | 추가 0원 |

---

## 1. 앱 주소 만들기 (GitHub Pages)

1. GitHub에서 새 저장소를 만들어요. 이름은 `thought-drawer`로 하고, 공개(Public)로 만들어요.
   공개라도 올라가는 건 앱 코드뿐이에요. 메모는 각자의 구글 드라이브에만 있어요.
2. 이 폴더의 파일을 그 저장소에 올려요(push).
3. 저장소의 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 고르고 저장해요.
4. 1~2분 뒤 앱 주소가 생겨요: `https://내아이디.github.io/thought-drawer/`

아래에서 이 주소를 **앱 주소**라고 불러요. 끝의 `/`까지 포함해요.

## 2. 구글 로그인 켜기 (Google Cloud)

1. <https://console.cloud.google.com> 에서 새 프로젝트를 만들어요. 이름은 `Thought Drawer`.
2. **API 및 서비스 → 라이브러리**에서 `Google Drive API`를 찾아 **사용**을 눌러요.
3. **Google 인증 플랫폼(OAuth 동의 화면)**을 열어요.
   - 앱 이름 `Thought Drawer`, 지원 이메일은 내 이메일. (이미 다른 이름으로 만들었다면 **브랜딩**에서 바꿀 수 있어요. 안 바꿔도 동작해요.)
   - 대상(사용자 유형)은 **외부**.
   - **데이터 액세스(범위)**에서 `.../auth/drive.file`을 추가해요. 앱이 만든 파일에만 접근하는 가장 좁은 권한이에요.
   - **브랜딩**에 아래를 넣고 저장해요. 로고는 넣지 마세요(로고를 넣으면 구글 심사가 필요해져요).
     - 애플리케이션 홈페이지: **앱 주소** (예: `https://내아이디.github.io/thought-drawer/`)
     - 개인정보처리방침 링크: 앱 주소 + `privacy.html`
     - 서비스 약관 링크: 앱 주소 + `terms.html`
     - 승인된 도메인: `내아이디.github.io`
   - **대상 → 앱 게시**를 눌러 "프로덕션"으로 바꿔요. drive.file만 쓰면 민감한 권한이 아니라서 별도 심사 없이 게시할 수 있어요.
     "테스트" 상태로 두면 자동 정리용 토큰이 7일마다 끊겨요.
4. **클라이언트 → 클라이언트 만들기**
   - 유형: **웹 애플리케이션**
   - 승인된 자바스크립트 원본: `https://내아이디.github.io`
   - 승인된 리디렉션 URI: **앱 주소** (예: `https://내아이디.github.io/thought-drawer/`)
   - 크롬 확장 프로그램도 쓸 거라면 리디렉션 URI를 하나 더 추가해요: `https://fifpgndooniiilnpibpjfkchpfmkppen.chromiumapp.org/`
5. 만들어진 **클라이언트 ID**를 `js/config.js`의 `GOOGLE_CLIENT_ID`에 붙여 넣고 다시 올려요.
6. **클라이언트 보안 비밀**은 따로 메모해 두세요. 4단계에서 써요. 이 값은 GitHub에 올리지 마세요.

이제 앱 주소를 열고 **Google로 계속하기**를 누르면 내 드라이브에 `메모` 폴더가 생겨요.

```
메모/
├─ 00_인박스/      새로 넣은 노트 (정리 대기)
├─ 패션/상의/      Claude가 만든 폴더들
├─ _첨부/          사진
└─ _시스템/        색인(index.json), 정리 기록
```

> 처음 로그인할 때 "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (앱 이름)(으)로 이동**을 눌러요. 내가 만든 앱이라 괜찮아요.

## 3. 폰, 다른 앱, 다른 브라우저에서 넣기

앱 오른쪽 위 동그란 메뉴의 **다른 앱·사이트에서 넣는 법**에 같은 안내와 QR 코드, 복사 버튼이 있어요.

**아이폰**
1. 사파리로 앱 주소를 열고 **공유 → 홈 화면에 추가**.
2. 홈 화면 앱에서 한 번, 사파리에서 한 번 로그인해요. 아이폰은 둘의 저장 공간을 따로 써요. 노트는 드라이브에 있어서 어느 쪽에서 봐도 같아요.
3. 아이폰은 애플 정책상 웹 앱이 **공유 목록에 직접 들어갈 수 없어요.** [단축어.md](단축어.md)를 따라 단축어 두 개를 한 번 만들어요: 링크·글은 「메모로 보내기」(Base64로 바꿔 보내서 누를 것 없이 저장), 캡처·사진은 「사진 보내기」(붙여넣기 한 번). 단축어를 잘못 만들면 앱이 무엇을 고칠지 알려 줘요.

**링크는 어느 서랍으로 가나요**: 주소로 알 수 있으면 그 서랍(무신사 → 패션·뷰티, 망고플레이트 → 요리·맛집, 상품 페이지 → 쇼핑). 주소 속 상품 이름(「…/린넨-셔츠/…」, 「…/women-dresses」)도 읽어요. 공유할 때 페이지 제목이 함께 오면 제목으로 정해요(「성수 파스타 맛집 후기」 → 요리·맛집). 블로그·카페·인스타·짧은 주소처럼 주소만으로 모르는 링크는 **링크** 서랍에 사이트별로 모아 두고, Claude 자동 정리가 내용을 읽어 제자리로 옮겨요.

**안드로이드**
1. **크롬**으로 앱 주소를 열고 **⋮ → 앱 설치**.
2. 설치하면 다른 앱의 **공유** 메뉴에 Thought Drawer가 나와요. 링크도, 캡처(사진)도 공유로 넣을 수 있어요.
3. 공유 목록에 안 보이면: 홈 화면의 Thought Drawer를 길게 눌러 지우고, 크롬에서 앱 주소를 열어 **⋮ → 앱 설치**로 다시 설치해요. 예전에 설치했거나 저장소를 비공개로 바꿨다 되돌린 뒤에는 다시 설치해야 새 공유 설정이 들어가요. 삼성 인터넷이나 「바로가기 추가」로 만든 아이콘은 공유 목록에 안 나와요.

**PC 크롬**: 확장 프로그램으로 보고 있는 페이지, 고른 글, 화면 캡처, 메모를 넣어요. [크롬확장.md](크롬확장.md)

## 4. 자동 정리 켜기 (Claude Code 예약 작업)

앱의 자동 분류는 낱말로 바로 나누는 **1차 분류**예요. 정밀한 분류가 필요해지면 이 단계를 켜세요.
Claude가 아직 폴더로 옮기지 않은 노트(「자동」 배지가 붙은 노트)만 읽고, 앱과 같은 서랍 이름으로 **대분류/중분류/소분류**를 정해 폴더로 옮기고,
제목·한 줄 요약·태그를 붙이고 관련 노트끼리 이어요. 직접 서랍을 정한 노트는 건드리지 않아요.
**지금 쓰는 Claude 구독으로 돌아서 API 비용이 없어요.** 사용량은 평소 Claude 쓰는 한도에서 같이 빠져요.

켜고 나면 앱의 **설정 → Claude 자동 정리**가 상태창이 돼요: 상태(켜짐·확인 필요·꺼짐), 마지막 정리, 정리한 노트, 정리 대기, 최근 정리한 노트.
시작 전에 구글 클라우드 **OAuth 동의 화면을 「프로덕션」으로 게시**해 두세요(2단계). 「테스트」면 토큰이 7일마다 끊겨요.

### 링크 내용을 읽게 하기 (네트워크)

Claude 정리기는 링크 페이지(블로그·쇼핑·인스타 릴스)의 제목과 내용을 읽어 제목·서랍·요약을 정해요. 그러려면 정리기 환경이 그 사이트에 접속할 수 있어야 해요.
claude.ai/code → 정리기 환경(Default) → 편집 → **네트워크 접근**을 **전체**로 바꾸거나, **제한** 그대로 두고 허용 도메인에 `instagram.com`, `naver.com`, `naver.me`, `coupang.com`, `musinsa.com`, `youtube.com` 처럼 자주 넣는 사이트를 더해요(패키지 관리자 허용 칸은 켠 채로). 막혀 있으면 정리기는 주소와 앱이 아는 정보만으로 정리해요.

### 비용 0원으로 지키기 (꼭)

- **Claude**: 클라우드 세션과 예약 작업은 구독(Pro 이상)의 사용 한도 안에서 돌고, 클라우드 컴퓨터 요금은 따로 없어요.
  돈이 나갈 수 있는 길은 두 가지뿐이라 둘 다 막아요.
  1. <https://claude.ai/settings/usage> 의 **사용량 크레딧(Usage credits, 예전 이름 추가 사용량)**을 켜지 않아요(켜져 있으면 꺼요). 꺼져 있으면 한도에 닿았을 때 예약 작업이 **결제 없이 멈췄다가** 한도가 다시 차면 이어서 돌아요.
  2. 환경 변수에 **`ANTHROPIC_API_KEY`나 `ANTHROPIC_AUTH_TOKEN`을 넣지 않아요.** 이게 있으면 구독 대신 API 요금으로 계산될 수 있어요. Claude Code가 API 크레딧을 권하면 거절해요.
- **구글 클라우드**: 드라이브 API와 구글 로그인은 무료예요. 프로젝트에 **결제 계정을 연결하지 않으면** 요금이 생길 수 없어요. 드라이브 용량(무료 15GB)이 차면 저장이 멈출 뿐 자동 결제되지 않아요.
- **GitHub**: 공개 저장소의 Pages와 Actions는 무료예요.
- 사용 한도를 아끼려면 예약 작업 모델은 **Haiku**, 일정은 하루 2~3번. 새 노트가 없으면 정리기가 바로 끝나요.

### 4-1. 정리기용 토큰 받기

1. 앱의 **설정 → Claude 자동 정리 → 정리기 연결 (토큰 받기)**에 클라이언트 보안 비밀을 넣고 **토큰 받기**를 눌러요.
2. 구글 허용 화면을 지나면 설정 화면에 토큰이 보여요. **복사**해 두세요. 이 화면을 벗어나면 다시 볼 수 없어요(다시 받으면 돼요).
3. 토큰과 보안 비밀은 **채팅창에 붙여 넣지 마세요.** 아래 환경 설정에만 넣어요.

### 4-2. Claude Code 환경 만들기

1. <https://claude.ai/code> 에서 이 GitHub 저장소를 연결해요.
2. 세션 위쪽의 클라우드 환경 메뉴 → **편집**에서:
   - **환경 변수(Environment variables)**에 세 개를 넣어요. 「Network secrets」 칸이 아니라 환경 변수 칸이어야 정리기가 읽을 수 있어요.
     - `TD_GOOGLE_CLIENT_ID` = 클라이언트 ID
     - `TD_GOOGLE_CLIENT_SECRET` = 클라이언트 보안 비밀
     - `TD_GOOGLE_REFRESH_TOKEN` = 4-1에서 받은 토큰
   - **네트워크 접근**: 북마크한 페이지까지 읽으려면 **전체(Full)**. 제한(Limited)으로 둘 때는 허용 도메인에 `googleapis.com`, `oauth2.googleapis.com`, `www.instagram.com`을 넣어요. 이 경우 일반 웹페이지 내용은 못 읽고 주소만으로 분류해요.
   - 자세한 화면 설명: <https://code.claude.com/docs/en/cloud-environments#network-access>
3. 새 세션에서 `python3 organizer/organize.py status`를 실행해 "정리 대기 N장"이 나오면 연결 성공이에요.

### 4-3. 예약 작업 만들기

claude.ai/code에서 예약 작업(scheduled task)을 새로 만들어요.

- 저장소: `thought-drawer`, 환경: 4-2에서 만든 환경
- 할 일(프롬프트): `organizer/ROUTINE.md 순서대로 Thought Drawer를 정리해줘.`
- 일정: 하루 2~3번 (예: 오전 8:47, 오후 1:47, 밤 9:47)
- 모델: **Haiku** (분류에는 충분하고 사용량이 가장 적어요)

또는 그 환경의 세션에서 Claude에게 "Thought Drawer 자동 정리 예약 작업 만들어줘. 하루 세 번, Haiku로"라고 말해도 돼요.

### 4-4. 필요할 때 지금 정밀 분류하기

- 예약 작업 화면에서 **지금 실행**을 누르거나, 그 환경에서 새 세션을 열고 `organizer/ROUTINE.md 순서대로 Thought Drawer를 정리해줘.`를 보내요.
- 한 번에 최대 30개씩 정리해요. 노트가 많으면 끝날 때까지 여러 번 실행해요(새 노트가 없으면 바로 끝나요).
- 더 꼼꼼하게 하려면 그때만 모델을 **Sonnet**으로 바꿔요. 사용량이 조금 더 들어요.
- 항상 같은 서랍에 넣고 싶은 것은 앱의 **분류 규칙**에 먼저 만들어 두세요. Claude도 그대로 따라요.
- 정리 결과가 마음에 안 들면 노트를 열어 서랍을 직접 바꿔요(Claude 사용 없음). Claude에게 다시 맡기고 싶은 노트만 노트 메뉴(⋯) → **Claude에게 다시 맡기기**를 누르면, 그 노트만 다음 정리 때 다시 분류돼요.

### 사용량을 아끼는 장치

- **한 번 정리한 노트는 다시 보내지 않아요.** Claude가 정리하면 노트에 정리한 시각(`organized`)이 남고, 정리기는 이 표시가 없는 새 노트만 보내요. 노트를 고치거나, 서랍을 「자동 분류」로 되돌려도 다시 보내지 않아요. 설정 → Claude 자동 정리의 **보내는 노트: 새 노트만**이 이 약속이에요.
- 새 노트가 없으면 스크립트가 바로 "정리할 노트 없음"을 내고 끝나요. 이때 쓰는 양은 아주 적어요(예약 작업이 켜져 확인하는 정도).
- 한 번에 최대 30개, 약 14,000자까지만 Claude에게 보여 줘요. 인스타 수백 개는 며칠에 나눠 정리돼요.
- 링크 내용 가져오기, 파일 옮기기, 연결 추가, 색인 만들기는 스크립트가 해요. Claude는 결정(JSON)만 써요.
- 캡처는 넣을 때 사진만 빨리 저장해요. Claude 정리 때 640픽셀로 줄인 사진을 Claude가 보고, 무엇인지 알아내 정리하면서 중요한 글자만 노트에 적어요(사진 한 장에 사용량이 조금 더 들어요).
- 인스타는 캡션·계정·컬렉션 이름만 읽어요. 영상은 분석하지 않아요.

### 서랍 이름이나 분류 설정이 바뀌면

다시 분류하지 않고 **이름만 바꿔요.** Claude 사용량이 들지 않아요.

- **서랍 이름 바꾸기**: 서랍 화면 오른쪽 위 메뉴 → **서랍 이름 바꾸기**. 정리된 노트는 새 이름 폴더로 옮기고(글과 「고친 시각」은 그대로), 비어 버린 옛 폴더는 드라이브 휴지통으로 가요. 자동 분류도, Claude 정리기도, 분류 규칙도 그때부터 새 이름을 써요. 이미 있는 서랍 이름으로 바꾸면 두 서랍이 합쳐져요.
- **바꾼 기록(장부)**: 설정 → **바꾼 서랍 이름**에 「옛 이름 → 새 이름」이 남아요. 드라이브 `메모/_시스템/settings.json`에 저장돼 폰·PC·정리기가 함께 봐요. 옛 이름에 노트가 남아 있으면(다른 기기에서 넣었거나 옮기다 끊긴 경우) **남은 노트 n개 → 옮기기**가 보여요. Claude 정리기도 실행될 때 남은 노트를 먼저 옮겨요(Claude 안 씀).
- **분류 규칙을 새로 만들거나 고치면**: 새 노트부터 규칙대로 들어가요. 이미 정리된 노트 중 규칙에 맞는 게 있으면 알림에 **그 노트도 옮기기**가 떠요. 누를 때만 옮겨요(Claude 안 씀).
- **앱 업데이트로 기본 서랍 이름이 바뀌면**: 앱이 가진 이름 장부(`js/core/taxonomy.js`의 `RENAMED`)대로 같은 방법으로 옮겨요. 이름을 장부에 적지 않고 바꾸면 테스트가 막아서, 정리된 노트가 길을 잃지 않아요.

## 5. 옵시디언, 노션으로 옮기기

- **옵시디언**: PC에 구글 드라이브 데스크톱 앱을 설치하고 `메모` 폴더를 동기화한 뒤, 옵시디언에서 그 폴더를 보관함으로 열어요. 노트의 `[[링크]]`, 사진, 태그가 그대로 보여요.
- **노션**: 앱의 **설정 → 노션용 zip 받기** → 노션 **가져오기 → 텍스트 및 마크다운**에 zip을 올려요.

## 6. 다른 사람도 쓰게 하기

지금은 「나만 쓰기」가 켜져 있어서 주인 계정만 쓸 수 있어요(7단계). 다른 사람도 쓰게 하려면 `js/config.js` 의 `OWNERS` 에 그 사람 메일 주소의 지문을 더하거나 비워요.
그러면 각자 자기 구글 계정으로 로그인하고, 노트는 **각자의 드라이브**에 저장돼요.
자동 정리는 각자 자기 Claude 구독으로 4단계를 따로 해야 해요. 내 구독을 다른 사람 정리에 쓰는 건 약관상 안 돼요.

## 7. 나만 쓰기와 보안

- **나만 쓰기**: `js/config.js` 의 `OWNERS` 에 주인 구글 계정의 지문(메일 주소의 SHA-256)이 들어 있어요. 다른 구글 계정으로 로그인하면 앱과 크롬 확장 프로그램이 연결을 끊고 「이 앱은 주인만 쓸 수 있어요」를 보여 줘요. 메일 주소 자체는 공개 코드에 두지 않아요.
  계정을 더하려면 그 메일 주소의 지문을 하나 더 넣어요(`config.js` 주석의 명령). 비우면 누구나 자기 계정으로 쓸 수 있어요.
- **노트는 원래 남이 못 봐요**: 노트는 내 구글 드라이브에 있고, 앱은 drive.file 권한(앱이 만든 파일만)으로만 열어요. 다른 사람이 앱 주소를 알아도 내 드라이브에는 들어올 수 없어요. 「나만 쓰기」는 남이 이 앱 자체를 쓰지 못하게 하는 문 잠금이에요.
- **저장소를 비공개로 바꾸면**: 무료 GitHub에서는 비공개 저장소로 GitHub Pages를 만들 수 없어서 **앱 주소가 꺼져요**. 유료(GitHub Pro)로 비공개 Pages를 써도 주소를 아는 사람은 페이지를 열 수 있어요. 그래서 저장소는 공개로 두고 「나만 쓰기」로 막는 것을 권해요. 저장소에는 비밀 값이 없어요(클라이언트 ID는 원래 공개용이고, 보안 비밀·토큰·노트는 저장소에 없음).
- **비밀 값은 어디에**: 클라이언트 보안 비밀과 정리기용 토큰은 claude.ai/code 환경 설정의 **환경 변수**에만 넣어요. 채팅창에 붙여 넣지 않아요. 이 값은 내 Claude 계정으로만 볼 수 있고, 그 환경에서 도는 정리기(Claude)가 드라이브에 연결할 때 써요.
- **토큰이 할 수 있는 일**: 앱이 만든 「메모」 폴더의 파일만 읽고 쓸 수 있어요. 메일, 사진, 다른 드라이브 파일은 못 건드려요.
- **끊고 싶을 때**: <https://myaccount.google.com/connections> (구글 계정 → 보안 → 타사 앱 및 서비스)에서 이 앱을 지우면 토큰이 바로 무효가 돼요. 보안 비밀이 걱정되면 구글 클라우드의 OAuth 클라이언트에서 새 보안 비밀을 만들고 예전 것을 지워요.
- **계정 지키기**: 구글 계정과 Claude 계정에 2단계 인증을 켜 두세요. 비밀 값은 결국 이 두 계정으로 보호돼요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 화면이 예전 그대로이거나 로그인 버튼이 없음 | 브라우저가 이전 파일을 잠깐(최대 10분) 기억해서 그래요. 새로 고침하거나 몇 분 뒤 다시 열어요. |
| 로그인 창이 안 뜸 (아이폰 홈 화면 앱) | 홈 화면 앱은 로그인 페이지로 이동했다가 돌아와요. 돌아오지 않으면 사파리에서 앱 주소를 열어 로그인해요. |
| `redirect_uri_mismatch` | 2-4단계의 리디렉션 URI가 앱 주소와 글자 하나까지 같은지(끝 `/` 포함) 확인해요. 크롬 확장 프로그램이라면 `chromiumapp.org` 주소를 추가했는지 봐요. |
| "드라이브에 연결하지 못했어요" | 화면 위 안내 줄이 원인과 고치는 버튼을 보여 줘요. **Drive API가 꺼져 있음**이면 버튼으로 구글 클라우드를 열어 **사용**을 누르고 몇 분 뒤 다시 시도해요. **권한이 허용되지 않음**이면 다시 연결하면서 「Google Drive」 항목을 체크해요. **자세히**를 누르면 구글이 보낸 원문이 나와요. |
| "구글 연결을 다시 받아야 해요"가 자꾸 뜸 | 서버 없는 웹앱이 구글에서 받는 연결 열쇠는 1시간짜리라서(구글 규칙) 앱이 저절로 새로 받아요. 앱을 열 때 만료됐으면 구글에 잠깐 다녀오고(1초쯤 흰 화면), 쓰는 중이면 클릭 한 번에 작은 창이 떴다 닫혀요. 그래도 띠가 뜨면: ① 그 브라우저(아이폰 홈 화면 앱이면 그 앱 안)에서 구글 로그인이 풀렸거나 ② 팝업이 막힌 경우예요. 「다시 연결」을 한 번 누르면 이어져요. 사파리 설정의 「팝업 차단」을 끄거나, 구글 계정에서 로그아웃하지 않으면 거의 안 떠요. |
| 정리기가 "구글 인증 실패" | 동의 화면이 "테스트" 상태라 토큰이 만료됐을 수 있어요. 프로덕션으로 바꾸고 4-1을 다시 해요. |
| 인스타 캡션을 못 읽음 | 비공개 계정 게시물이거나 인스타가 막은 경우예요. 계정·컬렉션 이름으로 분류하고, 정보가 너무 적으면 「생각·기록/메모」에 넣어요. |
| 드라이브에 `메모` 폴더가 두 개 | 앱은 자기가 만든 폴더만 볼 수 있어요. 직접 만든 `메모` 폴더는 이름을 바꿔 두세요. |
