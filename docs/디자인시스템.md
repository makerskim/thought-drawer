# 디자인 시스템

Thought Drawer 화면은 아래 규칙만으로 만든다. 새 화면을 만들 때도 여기서 고른다. 값은 `css/app.css` 맨 위 토큰에 있다.

## 원칙

1. **색은 아낀다.** 면은 중립 회색, 강조는 파랑 하나. 위계는 색이 아니라 글 크기·굵기·여백으로 만든다.
2. **모든 카드는 같은 종이다.** 흰(밤에는 짙은 회색) 면 + 얇은 테두리. 그라데이션, 종류별 바탕색은 쓰지 않는다.
3. **서랍은 작은 점으로만.** 서랍(분류) 색은 8px 점과 서랍 타일 아이콘에만 쓰고, 채도를 낮춘다.
4. **기기를 따른다.** 밝기는 기기 설정을 따르고, 설정에서 낮·밤으로 고정할 수 있다.
5. **짜임은 익숙하게.** 애플식 위 막대와 큰 제목, 넷플릭스식 서랍 줄, 옵시디언식 노트 작업 공간.

## 색

| 역할 | 토큰 | 낮 | 밤 |
|---|---|---|---|
| 바탕 | `--bg` | #f5f5f7 | #000000 |
| 종이(카드·창) | `--paper` | #ffffff | #1c1c1e |
| 옆 칸 | `--panel` | #fbfbfd | #0d0d0e |
| 옅은 면 | `--soft` / `--soft-2` | 검정 4% / 7% | 흰색 6% / 10% |
| 글 | `--text` / `--text-2` / `--text-3` | #1d1d1f / #6e6e73 / #8e8e93 | #f5f5f7 / #a1a1a6 / #6e6e73 |
| 선 | `--border` / `--border-2` | 검정 8% / 14% | 흰색 10% / 16% |
| 강조(단추) | `--accent` | #0071e3 | #0a84ff |
| 링크 | `--accent-ink` | #0066cc | #2997ff |
| 강조 바탕 | `--accent-soft` | 파랑 9% | 파랑 16% |
| 서랍 점 | `--d0`~`--d5` | 차분한 파랑·초록·호박·보라·산호·청록 | 한 단계 밝게 |
| 상태 | `--ok` `--warn` `--danger` | #34c759 #ff9f0a #ff3b30 | 같음 |

마스코트 서랍이는 파란 몸(`--m-body` #3b82f6, 밤 #4b8ff8)에 노란 쪽지 하나(`--m-note`). 표정은 smile · happy · wow · think · wave, 눈동자는 보는 쪽(`look`)으로 움직이고 가끔 깜빡인다.

## 글

Pretendard (애플 기기에서도 같은 글꼴). 굵기 400·500·600·700.

| 쓰임 | 크기 / 굵기 / 자간 |
|---|---|
| 첫 화면 큰 제목 | 34–56px / 700 / -0.035em |
| 화면 제목 (「서랍.」) | 30–40px / 700 / -0.035em |
| 노트 제목 | 34px (폰 27px) / 700 / -0.025em |
| 줄 제목 | 20px / 700 / -0.025em |
| 카드 제목 | 15px / 600 |
| 본문 | 15px, 노트 본문 16.5px / 400 / 줄 간격 1.55–1.75 |
| 보조 글 | 13–14px / 400 / `--text-2` |
| 작은 글 | 12px / `--text-3` |

화면 글(말투):

- **짧게.** 이름은 명사로(「사진·스크린샷」 「붙여넣기」 「결과 없음」), 설명은 한 문장. 같은 말을 두 번 하지 않는다.
- 부탁·감탄·이모지를 붙이지 않는다(「~해 보세요!」 대신 「~하세요.」 또는 이름만).
- 첫 화면 부제는 한 줄: 「무엇이든 넣으면 알아서 분류해드립니다.」 (줄바꿈 금지)
- 예외는 서랍이의 말풍선. 서랍이는 캐릭터라 말하듯 쓴다.

## 간격, 모서리, 그림자

- 간격: 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64. 화면 양옆 여백은 `--gut` (16px 또는 화면 폭의 4%).
- 모서리: 8 작은 조작(아이콘 단추, 태그) · 12 입력, 칩 안 · 16 카드, 타일 · 22 큰 면 · 999 주요 단추와 칩.
- 그림자: `--shadow-1` 거의 없음(기본) · `--shadow-2` 올렸을 때 · `--shadow-pop` 떠 있는 창. 카드는 기본으로 그림자 대신 1px 테두리.
- 높이: 작은 단추 32 · 기본 단추 38 · 큰 단추 48 · 위 막대 52.

## 부품

- **위 막대**: 52px, 반투명 + 흐림. 왼쪽 ☰와 이름, 오른쪽 찾기 · 내 메뉴.
- **옆 메뉴**: 288px(고정하면 264px). 36px 줄, 고른 줄은 옅은 면 + 굵게. 위에 찾기 칸, 아래에 설정. 핀으로 고정, ⇄로 왼쪽·오른쪽.
- **말풍선**: 종이 + 큰 그림자, 모서리 16(서랍이 쪽 아래만 4), 14px 글, 0.28초 튀어나옴.
- **두 번째 막대**: 서랍·설정 같은 화면에서 뒤로 + 화면 이름 + 오른쪽 보기 단추.
- **넣는 칸**: 첫 화면 세로 가운데, 680px, 종이 + 큰 그림자, 초점이면 파랑 테두리. 왼쪽 38px 동그란 **+**(누르면 넣는 방법 목록: 사진·스크린샷, 붙여넣기 | 북마크 가져오기, 인스타 가져오기, 다른 앱에서 넣기. 열리면 ×로 돈다), 오른쪽 「넣기」 알약(비었으면 회색). 위 왼쪽에 서랍이와 말풍선.
- **카드**: 256×224 (폰 220×204). 사진이 있으면 위 118px 사진. 위에서부터 출처(사이트 아이콘·이름) → 제목 2줄 → 발췌 3줄 → 바닥에 서랍 점·이름과 날짜. 올리면 2px 떠오른다.
- **서랍 줄**: 줄 제목 + 개수 + 「모두 보기 ›」. 카드는 옆으로 넘기고, PC에서는 양 끝에 동그란 화살표.
- **서랍 타일**: 아이콘(서랍 색) + 이름 + 노트 수 + 최근 노트 세 개.
- **칩**: 32px 알약, 고르면 글자색 바탕으로 뒤집힌다.
- **노트 작업 공간**: 세 칸(목록 260 · 본문 · 연결 300). 속성 표, 요약 콜아웃(파랑 옅은 바탕), 내 생각(노랑 옅은 바탕).
- **빠른 실행**: 680px 창, 20px 입력, 노트·명령 목록, 아래에 단축키 안내.
- **알림**: 짙은 알약, 동작은 파랑 글자.
