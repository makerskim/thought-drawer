# 아이폰 공유 단축어 만들기

아이폰은 애플 정책상 웹 앱이 공유 목록에 직접 들어갈 수 없어요. 대신 **단축어** 두 개를 한 번 만들어 두면
인스타, 사파리, 유튜브, 사진 앱의 **공유 버튼**에서 바로 Thought Drawer에 넣을 수 있어요.

| 단축어 | 무엇을 | 동작 | 쓸 때 누를 것 |
| --- | --- | --- | --- |
| **메모로 보내기** | 링크·글 | 2개 | 없음. 저절로 저장 |
| **사진 보내기** | 캡처·사진 | 5개 | 없음. 저절로 저장 (사진을 작게 줄여 글자로 바꿔 보내요) |

저장하면 그 노트가 열리고 **「저장한 이유」** 칸이 준비돼요. 거기에 한마디 적으면 함께 저장되고, 분류와 나중의 Claude 정리에도 쓰여요.

> 단축어는 글을 붙여 넣어서 만들 수 없어요(애플이 막아 둠). 동작을 **검색해서 하나씩** 넣고, **주소만 복사해서 붙여 넣어요.**
> 주소는 앱 오른쪽 위 동그라미 → **다른 앱·사이트에서 넣는 법** → 아이폰 칸의 **복사** 버튼으로도 복사할 수 있어요.

## 0. 시작 전에

- 사파리로 `https://makerskim.github.io/thought-drawer/` 를 열고 구글로 한 번 로그인해 두세요. 단축어는 앱을 사파리로 열어요.
- 예전에 만든 「메모로 보내기」·「사진 보내기」가 있으면 단축어 앱에서 길게 눌러 **삭제**하고 새로 만들어요.

## 1. 메모로 보내기 (링크·글)

1. **단축어** 앱 → 아래 **단축어** 탭 → 오른쪽 위 **+**.
2. 맨 위 「새로운 단축어」를 눌러 → **이름 변경** → `메모로 보내기` → 키보드 **완료**.
3. 화면 **맨 아래 ⓘ** 를 눌러요 (안 보이면 맨 위 이름을 눌러 나오는 메뉴의 **세부사항**).
   **공유 시트에서 보기**를 켜고 → 오른쪽 위 **완료**.
4. 아래 **작업 검색** 칸에 `URL` 을 쳐요. 결과 중 **그냥 「URL」**(🔗, 「URL 열기」 아님)을 눌러 넣어요.
5. 방금 넣은 「URL」 상자의 회색 칸을 눌러요. 들어 있는 글자가 있으면 지우고, 아래 주소를 **붙여 넣어요**.

   ```
   https://makerskim.github.io/thought-drawer/?text=
   ```
6. 커서가 주소 **맨 끝**에 있는 채로, **키보드 바로 위 줄**에서 **단축어 입력**을 눌러요.
   주소 뒤에 **파란 덩어리 「단축어 입력」**이 붙으면 맞아요. (글자로 「단축어 입력」이라고 치면 안 돼요.) 키보드 **완료**.
7. 다시 **작업 검색**에 `URL 열기` → **URL 열기**를 눌러 넣어요. 「**URL** 열기」로 보이면 맞아요(위 상자의 결과를 저절로 받아요).
8. 오른쪽 위 **완료**.

이렇게 두 상자가 되면 끝이에요.

```
┌ URL ───────────────────────────────────────────────┐
│ https://makerskim.github.io/thought-drawer/?text=[단축어 입력] │
└────────────────────────────────────────────────────┘
┌ [URL] 열기 ┐
└────────────┘
```

**시험해 보기**: 사파리에서 아무 페이지 → 공유 → (목록을 내려) **메모로 보내기**.
처음 한 번 「… makerskim.github.io …를 열도록 허용할까요?」가 나오면 **항상 허용**. 사파리가 열리고 저장된 노트가 보이면 성공이에요.

## 2. 사진 보내기 (캡처·사진, 자동)

사진을 640픽셀 폭으로 줄이고 글자(Base64)로 바꿔 주소에 실어 보내요. 앱은 받자마자 사진만 빨리 저장해요. 사진이 무엇인지는 Claude 정리 때 Claude가 사진을 보고 알아내 정리해요.
(아이폰 버전에 따라 상자 이름이 조금 달라요. 괄호 안이 다른 이름이에요.)

1. 단축어 앱 → **+** → 이름 `사진 보내기`.
2. 맨 아래 **ⓘ** → **공유 시트에서 보기** 켜기 → **완료**.
3. 아래 **검색**에 `크기` → **이미지 크기 변경**(이미지 크기 조절). 「크기 **640** x 자동 높이(으)로 **단축어 입력** 크기 변경」 그대로.
4. **검색**에 `이미지 변환` → **이미지 변환**. 「**크기 변경된 이미지**을(를) **JPEG**(으)로 변환」인지 확인.
5. **검색**에 `base64` → **Base64 인코딩**. 「base64로 **변환된 이미지** **인코딩**」 그대로.
   - 파란 「인코딩」 글자는 누르지 않아요(누르면 인코딩/디코딩 고르기예요. 「인코딩」 그대로).
6. **검색**에 `URL 인코딩` → **URL 인코딩**. 「**Base64로 인코딩됨** … URL **인코딩**」처럼 바로 위 상자의 결과를 받아요.
   (이 칸이 줄 바꿈과 특수 글자를 주소에 넣을 수 있는 꼴로 바꿔 줘서, 「유효하지 않은 URL」이 안 떠요.)
7. **검색**에 `URL` → 목록에서 **그냥 「URL」**(🔗 아이콘, 「URL 열기」 아님).
   - 그 상자의 칸을 눌러 들어 있는 글자를 **모두 지우고**, 아래 주소를 붙여 넣어요.

     ```
     https://makerskim.github.io/thought-drawer/#img=
     ```
   - 붙여 넣은 뒤 **엔터(return)나 띄어쓰기를 누르지 말고**, 키보드 바로 위 줄에서 **URL 인코딩됨**(URL 인코딩된 텍스트)을 눌러요.
     `#img=` 바로 뒤에 파란 덩어리가 **같은 줄에 붙어** 있어야 해요. 사이에 빈칸이나 줄 바꿈이 있으면 「유효하지 않은 URL」이 떠요.
   - 키보드 위 줄에 안 보이면 그 줄을 옆으로 밀어 찾거나, **변수 선택**을 누르고 6번 상자를 눌러요.
8. **검색**에 `URL 열기` → **URL 열기**. 「**URL** 열기」(바로 위 URL을 받음).
9. 오른쪽 위 **완료**(또는 ✓).

다 만들면 이렇게 일곱 상자예요.

```
공유 시트에서 … 받기
크기 640 x 자동 높이(으)로 단축어 입력 크기 변경
크기 변경된 이미지을(를) JPEG(으)로 변환
base64로 변환된 이미지 인코딩
Base64로 인코딩됨 URL 인코딩
URL  https://makerskim.github.io/thought-drawer/#img=[URL 인코딩됨]
URL 열기
```

이미 「URL」 상자를 만들었다면: 그 상자와 「URL 열기」 상자를 오른쪽 위 ⓧ 로 지운 뒤 6번부터 다시 넣는 게 가장 쉬워요.

**쓸 때**: 캡처 뒤 왼쪽 아래 미리보기(또는 사진 앱) → 공유 → **사진 보내기**. 사파리가 열리며 저장돼요.

**이 방법이 안 되면(붙여넣기 방식)**: 위 3~7을 지우고 **클립보드에 복사** → **URL 열기** `https://makerskim.github.io/thought-drawer/?paste=1` 두 개만 넣어요.
쓸 때 열린 화면의 **붙여넣기** → 바로 위에 뜨는 작은 「붙여넣기」를 한 번 더 눌러야 해요.

## 3. 공유 목록 맨 앞에 두기 (선택)

아무 앱에서 **공유** → 맨 아래 **작업 편집…** → 「메모로 보내기」「사진 보내기」 옆 **+** → **완료**.

## 쓰기

- 인스타: 게시물·릴스의 종이비행기 → 아래 줄의 **공유**(또는 「다른 앱」) → 메모로 보내기.
- 사파리·유튜브·쇼핑 앱·지도: 공유 → 메모로 보내기.
- 링크는 사이트 이름(무신사, 네이버 블로그…)을 함께 남기고, 제목이 없으면 「무신사 상품」「네이버 블로그 글」처럼 보여요.
  주소로 알 수 있으면 그 서랍(무신사 → 패션·뷰티, 망고플레이트 → 요리·맛집), 모르면 **링크** 서랍에 모였다가 Claude 정리 때 내용을 읽어 제자리로.
- 사진은 우선 「생각·기록 › 캡처」에 빨리 넣어 두고, Claude 정리 때 Claude가 사진 속 이름·글자를 보고 무엇인지 알아내 제자리로 옮겨요. 노트에는 **중요한 글자만**(상품·가게·가격·날짜 등) 남기고 시계·배터리·메뉴 같은 화면 글자는 넣지 않아요.

## 안 될 때 (앱이 무엇이 문제인지 알려 줘요)

| 앱에 나온 말 | 고칠 곳 |
| --- | --- |
| 「단축어가 보낸 내용이 비어 있어요」 | 1번 6단계: `?text=` 뒤에 파란 「단축어 입력」이 빠졌어요 |
| 「「단축어 입력」이 글자로 들어갔어요」 | 1번 6단계: 글자를 지우고 키보드 위 줄의 「단축어 입력」을 눌러요 |
| 「사진은 「사진 보내기」 단축어로」 | 사진은 2번 단축어로 공유해요 |
| 단축어가 「유효하지 않은 URL」 | 2번 6단계 「URL 인코딩」이 있는지, 7단계 `#img=` 바로 뒤에 파란 「URL 인코딩됨」이 빈칸·줄 바꿈 없이 붙었는지. URL 상자를 지우고 다시 넣는 게 가장 확실해요 |
| 「사진을 받지 못했어요」 | 7단계 파란 덩어리가 「URL 인코딩됨」(또는 「Base64로 인코딩됨」)인지. 그래도 안 되면 붙여넣기 방식으로 |
| 붙여넣기 화면이 떠요(링크를 공유했는데) | 1번 4단계에서 「URL」 대신 「클립보드에 복사」를 넣었거나, 주소가 `?paste=1`이에요 |
| 공유 목록에 없어요 | 3단계의 ⓘ → 「공유 시트에서 보기」를 켰는지, 공유 목록 맨 아래 「작업 편집…」에서 찾아봐요 |
| 사파리에 로그인 화면이 나와요 | 한 번 로그인하면 그 공유도 이어서 저장돼요 |
