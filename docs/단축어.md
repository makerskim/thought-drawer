# 아이폰 공유 단축어 만들기

아이폰은 애플 정책상 웹 앱이 공유 목록에 직접 들어갈 수 없어요. 대신 **단축어** 두 개를 한 번 만들어 두면
인스타, 사파리, 유튜브, 사진, 메모 앱의 **공유 버튼**에서 바로 Thought Drawer에 넣을 수 있어요.

| 단축어 | 무엇을 | 누를 것 |
| --- | --- | --- |
| **메모로 보내기** | 링크·글 | 없음. 공유하면 저장까지 저절로 |
| **사진 보내기** | 캡처·사진 | 「붙여넣기」 한 번 (사파리 보안 때문에 꼭 필요) |

> 단축어는 글을 붙여 넣어서 만들 수 없어요. 아래처럼 동작을 **검색해서 하나씩** 넣어요.

앱 주소: `https://makerskim.github.io/thought-drawer/` (다른 사람이 쓰면 `https://내아이디.github.io/thought-drawer/`)

## 0. 먼저 사파리에서 로그인

단축어는 앱을 **사파리**로 열어요. 사파리로 앱 주소를 열고 구글로 한 번 로그인해 두세요.
그 뒤로는 열쇠가 만료돼도 구글에 잠깐 다녀와서 저절로 이어져요.

## 1. 「메모로 보내기」 (링크·글, 자동)

예전에 「메모로 보내기」를 만들었다면 먼저 길게 눌러 **삭제**해요.

1. **단축어** 앱 → 아래 **단축어** 탭 → 오른쪽 위 **+** → 맨 위 이름을 `메모로 보내기`로.
2. 이름 옆 **∨** → **세부사항** → **공유 시트에서 보기** 켜기 → **완료**.
   맨 위에 「공유 시트에서 **…** 입력 받기」 줄이 생기면 파란 글자를 눌러 **URL**과 **텍스트**만 켜요.
3. 동작 검색에 `URL 인코딩` → **URL 인코딩** 추가. 「**단축어 입력** URL 인코딩」으로 보이면 맞아요.
4. 동작 검색에 `URL` → 맨 위의 **URL** 추가 (「URL 열기」 말고 그냥 「URL」).
   칸을 눌러 아래 주소를 붙여 넣고, **커서를 맨 끝에 둔 채** 키보드 위 변수 줄에서 **URL 인코딩된 텍스트**를 눌러요.

   ```
   https://makerskim.github.io/thought-drawer/?text=
   ```
   → 칸이 「…/thought-drawer/?text=**URL 인코딩된 텍스트**」가 돼요.
5. 동작 검색에 `URL 열기` → **URL 열기** 추가. 「**URL** 열기」로 보이면 맞아요.
6. **완료**.

다 만들면 세 줄이에요.

- 단축어 입력 **URL 인코딩**
- **URL** https://makerskim.github.io/thought-drawer/?text=[URL 인코딩된 텍스트]
- **URL** 열기

## 2. 「사진 보내기」 (캡처·사진)

1. 단축어 앱 → **+** → 이름 `사진 보내기`.
2. **∨** → **세부사항** → **공유 시트에서 보기** 켜기 → 맨 위 파란 글자를 눌러 **이미지**만 켜요.
3. **클립보드에 복사** 추가 (「단축어 입력 클립보드에 복사」).
4. **URL 열기** 추가 → 칸에 아래 주소.

   ```
   https://makerskim.github.io/thought-drawer/?paste=1
   ```
5. **완료**.

## 3. 쓰기

- **링크** (사파리·인스타·유튜브·쇼핑 앱·지도): 공유 → **메모로 보내기**. 사파리가 열리면서 저절로 저장되고 그 노트가 열려요.
  인스타는 종이비행기 → 아래 줄의 **공유**(또는 「다른 앱」) → 메모로 보내기.
- **메모 앱의 글**: 글을 선택해 공유 → 메모로 보내기.
- **캡처·사진**: 캡처 뒤 왼쪽 아래 미리보기(또는 사진 앱) → 공유 → **사진 보내기** → 열린 화면의 **붙여넣기** → 바로 위에 뜨는 작은 **「붙여넣기」**를 한 번 더.
- 처음 한 번은 「…이(가) makerskim.github.io에 접근하도록 허용할까요?」가 나와요 → **허용**(또는 항상 허용).
- 공유 목록 맨 앞에 두기: 공유 → 맨 아래 **작업 편집…** → 두 단축어 옆 **+** → **완료**.

공유할 때 링크면 「메모로 보내기」만, 사진이면 「사진 보내기」만 목록에 나와요.

## 어느 서랍에 들어가나요

- 주소로 알 수 있는 링크는 그 서랍(무신사 → 패션·뷰티, 망고플레이트 → 요리·맛집, 상품 페이지 → 쇼핑, 주소 속 상품 이름도 읽어요).
- 블로그·인스타·naver.me 같은 짧은 주소처럼 주소만으로 모르는 링크는 **링크** 서랍에 사이트별로 모였다가, Claude 자동 정리가 내용을 읽어 제자리로 옮겨요.

## 안 될 때

- **공유 목록에 안 나와요**: 「공유 시트에서 보기」를 켰는지, 받는 유형(메모로 보내기: URL·텍스트, 사진 보내기: 이미지)이 맞는지 봐요. 공유 목록 맨 아래 **작업 편집…**에서도 찾아봐요.
- **사파리에 「붙여넣기」 화면이 떠요(링크를 공유했는데)**: 예전 「메모로 보내기」예요. 지우고 1번대로 다시 만들어요.
- **빈 화면이나 「저장하지 못했어요」**: 1번 4단계의 URL 칸이 `…/thought-drawer/?text=` 뒤에 **URL 인코딩된 텍스트**(파란 덩어리)가 붙은 모양인지 확인해요. 글자로 「URL 인코딩된 텍스트」라고 직접 치면 안 돼요.
- **사파리에 로그인 화면이 나와요**: 한 번 로그인하면 그 공유도 이어서 저장돼요.
- **사진이 안 들어가요**: 붙여넣기 버튼을 누른 뒤, 그 바로 위에 뜨는 작은 「붙여넣기」를 눌러야 해요.
