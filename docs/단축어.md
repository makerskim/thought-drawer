# 아이폰 「메모로 보내기」 단축어 만들기

인스타, 사파리, 사진, 메모 앱의 **공유 버튼**에서 바로 생각서랍에 넣는 단축어예요. 5분이면 만들어요.
아래에서 `앱주소`는 `https://내아이디.github.io/thought-drawer/` 처럼 끝이 `/`인 내 앱 주소예요.

## 만들기

1. **단축어** 앱 → 오른쪽 위 **+** → 이름을 `메모로 보내기`로 바꿔요.
2. 아래 **ⓘ(정보)** → **공유 시트에서 보기**를 켜요.
   맨 위 "공유 시트에서 받기"의 유형은 **이미지, URL, 텍스트, Safari 웹 페이지**만 남겨요.
3. 동작을 이렇게 넣어요.

```
만약 [단축어 입력] 의 [유형] 이(가) [이미지] 이면
    [단축어 입력] 을 클립보드에 복사
    URL 열기: 앱주소?paste=1
그렇지 않으면
    텍스트: [단축어 입력]
    [텍스트] 을(를) URL 인코딩
    URL 열기: 앱주소?text=[URL 인코딩된 텍스트]
만약 끝
```

- "만약"은 **스크립트 작성 → 만약**에서 찾아요. 조건은 **단축어 입력 → 유형 → 이미지**.
- "URL 인코딩"은 검색창에 `URL 인코딩`을 쳐서 넣어요.
- "URL 열기"의 주소 칸에 `앱주소?text=`까지 직접 쓰고, 그 뒤에 변수 **URL 인코딩된 텍스트**를 넣어요.

## 쓰기

- **인스타그램**: 게시물이나 릴스의 종이비행기(공유) → 공유 시트 맨 아래 **메모로 보내기**.
  앱이 열리면서 정리 대기에 인스타 카드가 생기고, 다음 정리 때 캡션을 읽어 분류돼요.
- **사파리**: 공유 → 메모로 보내기. 주소가 북마크 카드가 돼요.
- **사진, 캡처**: 캡처 뒤 미리보기를 눌러 공유 → 메모로 보내기. 앱의 사진 화면이 열리면 **붙여넣기**를 한 번 눌러요.
  (아이폰 보안 때문에 사진은 이 한 번이 필요해요.)
- **메모 앱의 글**: 글을 선택해 공유 → 메모로 보내기. 메모 카드가 돼요.

## 참고

- 단축어로 연 앱은 **사파리**에서 열려요. 사파리에서 한 번 구글로 로그인해 두세요.
- 공유할 때 한 줄 메모를 같이 넣고 싶으면, 공유할 글에 링크와 메모를 함께 넣으면 돼요. 링크는 출처로, 나머지 글은 "내 생각"으로 들어가요.
