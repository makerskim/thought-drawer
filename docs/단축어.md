# 아이폰 「메모로 보내기」 단축어 만들기

아이폰은 애플 정책상 웹 앱이 공유 목록에 직접 들어갈 수 없어요. 대신 **단축어** 하나를 만들어 두면
인스타, 사파리, 사진, 메모 앱의 **공유 버튼**에서 바로 Thought Drawer에 넣을 수 있어요. 동작은 **두 개**뿐이에요.

> 단축어는 글을 붙여 넣어서 만들 수 없어요. 아래처럼 동작을 **검색해서 하나씩** 넣어요.

앱 주소: `https://makerskim.github.io/thought-drawer/` (다른 사람이 쓰면 `https://내아이디.github.io/thought-drawer/`)

## 0. 먼저 사파리에서 로그인

단축어는 앱을 **사파리**로 열어요. 사파리로 앱 주소를 열고 구글로 한 번 로그인해 두세요.
(홈 화면에 추가한 앱과 사파리는 로그인을 따로 기억해요. 노트는 드라이브에 있어서 어디서 봐도 같아요.)

## 1. 새 단축어

1. **단축어** 앱 → 아래 **단축어** 탭 → 오른쪽 위 **+**.
2. 맨 위 이름을 눌러 **이름 변경** → `메모로 보내기`.
3. 이름 옆 **∨** → **세부사항** → **공유 시트에서 보기** 켜기 → **완료**.

## 2. 동작 두 개

1. 아래 **동작 검색**에 `클립보드` → **클립보드에 복사**를 눌러 넣어요.
   「**단축어 입력** 클립보드에 복사」로 보이면 맞아요. (「단축어 입력」이 아니면 그 칸을 눌러 **단축어 입력**을 골라요.)
2. 다시 **동작 검색**에 `URL 열기` → **URL 열기**를 눌러 넣어요.
   파란 **URL** 칸을 눌러 지우고 아래 주소를 붙여 넣어요.

   ```
   https://makerskim.github.io/thought-drawer/?paste=1
   ```
3. 오른쪽 위 **완료**.

다 만들면 이렇게 두 줄이에요.

- 단축어 입력 → **클립보드에 복사**
- **URL 열기** https://makerskim.github.io/thought-drawer/?paste=1

## 3. 쓰기

1. 아무 앱에서 **공유** → **메모로 보내기**.
   - 인스타: 게시물·릴스의 종이비행기 → 아래 줄의 **공유**(또는 「다른 앱」) → 메모로 보내기
   - 캡처: 찍은 뒤 왼쪽 아래 미리보기 → 공유 → 메모로 보내기 (사진 앱에서 공유해도 돼요)
2. 사파리가 열리고 「공유한 것을 넣어요」 화면이 나와요. 파란 **붙여넣기** 버튼을 눌러요.
3. 버튼 **바로 위에 작은 검은 말풍선 「붙여넣기」**가 떠요. **그걸 한 번 더** 눌러요.
   (사파리는 보안 때문에 사이트가 복사해 둔 것을 혼자 읽지 못해요. 이 말풍선을 눌러야 넘어가요.)
   말풍선이 안 보이면 아래 점선 칸을 **길게** 눌러 나오는 **붙여넣기**를 눌러도 돼요.
4. 저장되고 그 노트가 열려요. 링크·글·사진 모두 같아요.

- 처음 한 번은 「메모로 보내기가 makerskim.github.io에 접근하도록 허용할까요?」가 나와요 → **허용**.
- 공유 목록 맨 앞에 두기: 공유 → 맨 아래 **작업 편집…** → 「메모로 보내기」 옆 **+** → **완료**.

## 어느 서랍에 들어가나요

- 주소로 알 수 있는 링크는 그 서랍(무신사 → 패션·뷰티, 망고플레이트 → 요리·맛집, 상품 페이지 → 쇼핑, 주소 속 상품 이름도 읽어요).
- 블로그·인스타·naver.me 같은 짧은 주소처럼 주소만으로 모르는 링크는 **링크** 서랍에 사이트별로 모였다가, Claude 자동 정리가 내용을 읽어 제자리로 옮겨요.

## 안 될 때

- **공유 목록에 「메모로 보내기」가 없어요**: 1단계 3번의 「공유 시트에서 보기」를 켰는지 확인해요. 공유 목록 맨 아래 **작업 편집…**에서도 찾아봐요.
- **「공유한 것을 넣어요」에서 멈춰요**: 단축어는 제대로 된 거예요. 파란 버튼을 누른 뒤, 그 위에 뜨는 작은 「붙여넣기」 말풍선을 한 번 더 눌러야 해요. 안 보이면 점선 칸을 길게 눌러 붙여넣기.
- **사파리에 로그인 화면이 나와요**: 로그인하면 「공유한 것을 넣어요」 화면으로 이어져요. 다음부터는 바로 나와요.
- **「복사해 둔 링크·글·사진이 없어요」**: 2단계 1번이 「**단축어 입력** 클립보드에 복사」인지 확인해요.
- **엉뚱한 화면이 열려요**: 2단계 2번 주소 끝이 `?paste=1`인지 확인해요.
- **예전에 만든 복잡한 단축어**(만약·URL 인코딩이 있는 것)는 지우고 이 두 줄짜리로 다시 만들어요.
