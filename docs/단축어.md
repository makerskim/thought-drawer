# 아이폰 공유 단축어 만들기

아이폰은 애플 정책상 웹 앱이 공유 목록에 직접 들어갈 수 없어요. 대신 **단축어** 두 개를 한 번 만들어 두면
인스타, 사파리, 유튜브, 네이버 쇼핑, 지도, 메모 앱, 사진 앱의 **공유 버튼**에서 바로 Thought Drawer에 넣을 수 있어요.

| 단축어 | 무엇을 | 상자 | 쓸 때 |
| --- | --- | --- | --- |
| **메모로 보내기** | 링크·글 | 4개 | 누를 것 없이 저장 |
| **사진 보내기** | 캡처·사진 | 2개 | 「붙여넣기」 → 바로 위 작은 「붙여넣기」 (사파리 보안 때문에 꼭 필요) |

> 단축어는 글을 붙여 넣어서 만들 수 없어요(애플이 막아 둠). 동작을 **검색해서 하나씩** 넣고, **주소만 복사해서 붙여 넣어요.**
> 주소는 앱 오른쪽 위 동그라미 → **다른 앱·사이트에서 넣는 법** → 아이폰 칸의 **복사** 버튼으로 복사하면 줄 바꿈 없이 들어가요.

마지막 상자는 **「URL 열기」**예요. 사파리에 탭이 하나씩 생겨요. 저장되면 왼쪽 위 「◀ 원래 앱」으로 돌아가고, 쌓인 탭은 아이폰 **설정 → 앱 → Safari → 탭 닫기 → 하루 후**로 저절로 닫히게 해요.

## 0. 시작 전에

- 예전에 만든 「메모로 보내기」「사진 보내기」는 단축어 앱에서 길게 눌러 **삭제**하고 새로 만들어요.
- 사파리로 앱 주소를 열고 **구글로 한 번 로그인**해 둬요.

## 1. 메모로 보내기 (링크·글)

공유한 글을 **Base64**(글자를 영어·숫자로 바꾼 것)로 바꿔서 보내요. 그래야 글 속의 `https://…`가 그대로 남아 아이폰이 주소를 둘로 읽는 일이 없어요(탭이 두 개 열리고 빈 내용이 가던 문제).

1. **단축어** 앱 → 아래 **단축어** 탭 → 오른쪽 위 **+** → 맨 위 이름을 눌러 **이름 변경** → `메모로 보내기`.
2. 화면 **맨 아래 가운데 ⓘ** → **공유 시트에서 보기** 켜기 → **완료**.
   맨 위 「공유 시트에서 **앱 및 18개** 받기」는 **그대로(모두 켠 채로)** 둬요. 줄이면 메모 앱 글 같은 것이 빈 내용으로 넘어가요.
3. 아래 **검색**에 `base64` → **Base64 인코딩**. 「base64로 **단축어 입력** 인코딩」으로 보이면 맞아요.
   - 칸이 회색 「입력」이면 눌러서 **단축어 입력**을 골라요. 파란 「인코딩」 글자는 누르지 않아요.
4. **검색**에 `URL 인코딩` → **URL 인코딩**. 「**Base64로 인코딩됨** 을(를) URL 인코딩」으로 보이면 맞아요.
5. **검색**에 `URL` → 목록에서 **그냥 「URL」**(🔗 아이콘). 칸을 눌러 들어 있는 글자를 **모두 지우고** 붙여 넣어요.

   ```
   https://makerskim.github.io/thought-drawer/#t=
   ```
6. 엔터·띄어쓰기 없이, 키보드 바로 위 줄의 **URL 인코딩된 텍스트**를 눌러 끝에 붙여요(파란 덩어리).
7. **검색**에 `URL 열기` → **URL 열기**. 「**URL** 열기」로 바로 위 URL을 받으면 맞아요.
8. 오른쪽 위 **완료**.

다 만들면 이렇게 돼요.

```
공유 시트에서 앱 및 18개 받기
base64로 단축어 입력 인코딩
Base64로 인코딩됨 을(를) URL 인코딩
URL  https://makerskim.github.io/thought-drawer/#t=[URL 인코딩된 텍스트]
URL 열기
```

## 2. 사진 보내기 (캡처·사진)

1. **+** → 이름 `사진 보내기`.
2. 맨 아래 **ⓘ** → **공유 시트에서 보기** 켜기 → **완료**.
3. **검색**에 `클립보드에 복사` → **클립보드에 복사**. 「**단축어 입력** 클립보드에 복사」로 보이면 맞아요.
4. **검색**에 `URL 열기` → **URL 열기** → 파란 「URL」 자리를 눌러 이 주소를 붙여 넣어요.

   ```
   https://makerskim.github.io/thought-drawer/?paste=1
   ```
5. **완료**.

**쓸 때**: 캡처 → 왼쪽 아래 미리보기(또는 사진 앱) → 공유 → **사진 보내기** → 뜬 화면의 **붙여넣기** → 그 바로 위 작은 **「붙여넣기」**.
사진을 주소에 실어 누를 것 없이 보내는 방법도 있지만, 아이폰이 긴 주소를 막는 경우가 많아 이 방법을 써요.

## 3. 쓰기

- 인스타: 게시물·릴스의 종이비행기 → 아래 줄의 **공유**(또는 「다른 앱」) → 메모로 보내기.
- 사파리·유튜브·쇼핑 앱·지도: 공유 → 메모로 보내기.
- 메모 앱: 넣을 글을 길게 눌러 고른 뒤 **공유** → 메모로 보내기(메모 전체는 위쪽 공유 → 메모로 보내기).
- 저장되면 그 노트가 열리고 「저장한 이유」에 한마디 적을 수 있어요. 다 됐으면 왼쪽 위 「◀ 원래 앱」으로 돌아가요.
- 처음 한 번 「…makerskim.github.io…를 열도록 허용할까요?」가 나오면 **항상 허용**.
- 공유 목록 맨 앞에 두기: 공유 → 맨 아래 **작업 편집…** → 두 단축어 옆 **+** → **완료**.

## 어느 서랍에 들어가나요

- 링크는 사이트 이름(무신사, 네이버 블로그…)을 함께 남기고, 제목이 없으면 「무신사 상품」「네이버 블로그 글」처럼 보여요.
  주소로 알 수 있으면 그 서랍(무신사 → 패션·뷰티, 망고플레이트 → 요리·맛집), 모르면 **링크** 서랍에 모였다가 Claude 정리 때 내용을 읽어 제자리로.
- 사진은 우선 「생각·기록 › 캡처」에 빨리 넣어 두고, Claude 정리 때 Claude가 사진 속 이름·글자를 보고 무엇인지 알아내 제자리로 옮겨요. 노트에는 **중요한 글자만** 남겨요.

## 안 될 때 (앱이 무엇이 문제인지 알려 줘요)

| 나온 말 | 고칠 곳 |
| --- | --- |
| 단축어가 「유효하지 않은 URL」 | 1번 5~6단계: URL 칸 `#t=` 바로 뒤에 파란 「URL 인코딩된 텍스트」가 빈칸·줄 바꿈 없이 붙었는지. URL 상자를 ⓧ로 지우고 다시 넣는 게 가장 확실해요 |
| 앱에 「단축어가 보낸 내용이 비어 있어요」 | 3단계 base64 칸이 「단축어 입력」인지(회색 「입력」이면 비어 있음), 6단계 파란 덩어리가 있는지, 2단계 받는 유형이 모두 켜져 있는지 |
| 앱에 「「단축어 입력」이 글자로 들어갔어요」 | 파란 덩어리 대신 글자를 쳤어요. 지우고 키보드 위 줄에서 눌러 넣어요 |
| 앱에 「사진은 「사진 보내기」 단축어로」 | 사진은 2번 단축어로 공유해요 |
| 사진: 붙여넣기 뒤 아무 일도 없음 | 파란 버튼을 누른 뒤 그 **바로 위** 작은 검은 「붙여넣기」를 한 번 더 눌러요 |
| 사파리에 로그인 화면 | 한 번 로그인하면 그 공유도 이어서 저장돼요 |
| 사파리에 탭이 쌓여요 | 단축어로는 막을 수 없어요. 설정 → 앱 → Safari → 탭 닫기 → 하루 후 |
| 공유 목록에 없어요 | ⓘ → 「공유 시트에서 보기」를 켰는지, 공유 목록 맨 아래 「작업 편집…」에서 찾아봐요 |
