# 아이폰 「메모로 보내기」 단축어 만들기

아이폰은 애플 정책상 웹 앱이 공유 목록에 직접 들어갈 수 없어요. 대신 **단축어** 하나를 만들어 두면
인스타, 사파리, 사진, 메모 앱의 **공유 버튼**에서 바로 Thought Drawer에 넣을 수 있어요. 한 번만 만들면 돼요(5분).

앱 주소: `https://makerskim.github.io/thought-drawer/` (다른 사람이 쓰면 `https://내아이디.github.io/thought-drawer/`)

## 0. 먼저 사파리에서 로그인

단축어는 앱을 **사파리**로 열어요. 사파리로 앱 주소를 열고 구글로 한 번 로그인해 두세요.
(홈 화면에 추가한 앱과 사파리는 로그인을 따로 기억해요. 노트는 드라이브에 있어서 어디서 봐도 같아요.)

## 1. 새 단축어

1. **단축어** 앱 → 아래 **단축어** 탭 → 오른쪽 위 **+**.
2. 맨 위 이름을 눌러 **이름 변경** → `메모로 보내기`.

## 2. 공유 목록에 나오게

1. 맨 위 이름 옆 **∨** (또는 아래 **ⓘ**) → **세부사항** → **공유 시트에서 보기** 켜기 → **완료**.
2. 편집 화면 맨 위에 「공유 시트에서 **이미지 및 18개 이상**의 입력 받기」 같은 줄이 생겨요.
   파란 글자(**이미지 및 18개 이상**)를 눌러 **모두 끄고 이미지, URL, 텍스트 세 개만** 켜요.

## 3. 동작 넣기 (아래 검색창에 이름을 쳐서 추가)

```
입력에서 이미지 가져오기        ← 「단축어 입력」에서
만약 [이미지] 값이 있음
    [이미지] 클립보드에 복사
    URL: 앱주소?paste=1
    URL 열기
그렇지 않으면
    [단축어 입력] URL 인코딩
    URL: 앱주소?text=[URL 인코딩된 텍스트]
    URL 열기
만약 끝
```

1. **입력에서 이미지 가져오기** 추가. 「단축어 입력에서 이미지 가져오기」로 보이면 그대로 둬요.
2. **만약** 추가 → 조건을 눌러 **값이 있음**. 왼쪽이 **이미지**인지 확인해요.
   「그렇지 않으면」과 「만약 끝」이 함께 생겨요.
3. **만약**과 **그렇지 않으면** 사이에:
   - **클립보드에 복사** (입력: 이미지)
   - **URL** → 칸에 `https://makerskim.github.io/thought-drawer/?paste=1`
   - **URL 열기**
4. **그렇지 않으면**과 **만약 끝** 사이에:
   - **URL 인코딩** → 파란 칸을 눌러 **단축어 입력**을 고르고, 「인코딩」인지 확인
   - **URL** → 칸에 `https://makerskim.github.io/thought-drawer/?text=` 를 쓰고, 바로 뒤에 키보드 위 변수 줄에서 **URL 인코딩된 텍스트**를 눌러 붙여요
   - **URL 열기**
5. 오른쪽 위 **완료**.

동작 순서를 잘못 넣었으면 길게 눌러 끌어 옮겨요.

## 4. 공유 목록 맨 앞에 두기 (선택)

아무 앱에서 **공유** → 아래로 내려 **작업 편집…** → **메모로 보내기** 옆 **+** (즐겨찾기) → **완료**.

## 쓰기

- **링크 (사파리·인스타·유튜브·쇼핑 앱)**: 공유 → **메모로 보내기**. 사파리가 열리면서 링크 노트가 저장돼요.
  인스타는 게시물·릴스의 종이비행기 → 아래 줄의 **공유**(또는 「다른 앱」) → 메모로 보내기.
- **캡처·사진**: 캡처 뒤 왼쪽 아래 미리보기를 눌러 공유(또는 사진 앱에서 공유) → **메모로 보내기**.
  「사진 붙여넣기」 화면이 열리면 **붙여넣기** → 아이폰이 물으면 **붙여넣기 허용**. 사진 노트가 되고 사진 속 글자도 읽어요.
  (아이폰 보안 때문에 사진은 이 한 번의 누름이 필요해요.)
- **메모 앱의 글**: 글을 선택해 공유 → 메모로 보내기. 메모 노트가 돼요.
- 처음 한 번은 「메모로 보내기가 makerskim.github.io에 접근하도록 허용할까요?」가 나와요 → **허용**(또는 항상 허용).

## 어느 서랍에 들어가나요

- 주소로 알 수 있는 링크는 그 서랍(무신사 → 패션·뷰티, 망고플레이트 → 요리·맛집, 상품 페이지 → 쇼핑, 주소 속 상품 이름도 읽어요).
- 블로그·인스타·naver.me 같은 짧은 주소처럼 주소만으로 모르는 링크는 **링크** 서랍에 사이트별로 모였다가, Claude 자동 정리가 내용을 읽어 제자리로 옮겨요.

## 안 될 때

- **공유 목록에 「메모로 보내기」가 없어요**: 2단계의 「공유 시트에서 보기」가 켜졌는지, 받는 유형에 이미지·URL·텍스트가 켜졌는지 확인해요. 공유 목록 맨 아래 **작업 편집…**에서도 찾아봐요.
- **사파리에 로그인 화면이 나와요**: 사파리에서 한 번 로그인하면 다음부터는 바로 저장돼요.
- **「저장하지 못했어요」나 빈 화면**: 3단계 4번의 URL 칸이 `…/thought-drawer/?text=` 뒤에 **URL 인코딩된 텍스트** 변수가 붙어 있는지 확인해요.
- **사진이 안 들어가요**: 붙여넣기 화면에서 **붙여넣기** 버튼을 누르고 「붙여넣기 허용」을 눌러야 해요. 거절했다면 다시 공유해요.
