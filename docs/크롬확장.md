# 크롬 확장 프로그램

보고 있는 페이지, 고른 글, 화면 캡처, 이미지, 메모를 구글 드라이브 「메모」 폴더의 **인박스**에 바로 넣어요.
웹사이트, 폰 앱과 같은 곳에 저장되고, Claude 정리기가 나중에 제목, 폴더, 태그, 연결을 붙여요.

## 설치

1. 앱 오른쪽 위 동그란 메뉴 → **다른 앱·사이트에서 넣는 법** → **웹사이트** 탭 → **확장 프로그램 받기 (zip)** 를 눌러요.
   (주소로 받기: 앱 주소 + `downloads/thought-drawer-chrome.zip`)
2. zip의 압축을 풀어요. 풀린 `thought-drawer-chrome` 폴더는 지우지 말고 둬요. 크롬이 이 폴더에서 확장 프로그램을 읽어요.
3. 크롬 주소창에 `chrome://extensions` 를 열어요.
4. 오른쪽 위 **개발자 모드**를 켜고 **압축해제된 확장 프로그램 로드** → 푼 폴더를 골라요.
5. 주소창 옆 퍼즐 아이콘에서 Thought Drawer를 **고정**해요.
6. 설치하면 열리는 탭에서 **구글로 연결**을 눌러요.

### 처음 한 번: 구글 클라우드에 주소 추가

확장 프로그램은 웹사이트와 같은 구글 로그인(클라이언트 ID)을 써요. 구글이 확장 프로그램으로 돌아오도록 주소를 하나 등록해야 해요.

1. <https://console.cloud.google.com/auth/clients> 에서 웹사이트용으로 만든 **웹 애플리케이션** 클라이언트를 열어요.
2. **승인된 리디렉션 URI**에 아래 주소를 추가하고 저장해요.

   ```
   https://fifpgndooniiilnpibpjfkchpfmkppen.chromiumapp.org/
   ```

3. 저장이 반영되기까지 몇 분 걸릴 수 있어요. 연결 창에 `redirect_uri_mismatch`가 나오면 잠시 뒤 다시 눌러요.

확장 프로그램 번호(`fifpgndooniiilnpibpjfkchpfmkppen`)는 `manifest.json`의 `key`로 고정돼 있어서, 어느 컴퓨터에 설치해도 같아요.

## 쓰는 법

| 하고 싶은 것 | 방법 |
|---|---|
| 보고 있는 페이지 넣기 | 아이콘 누르기 (또는 `Ctrl+Shift+Y`, 맥 `⌘+Shift+Y`) → **페이지 넣기**. 생각 한 줄을 같이 적을 수 있어요. |
| 고른 글 넣기 | 글을 고른 채로 아이콘을 누르면 인용으로 같이 들어가요. 오른쪽 클릭 → **Thought Drawer → 고른 글 넣기** 도 돼요. |
| 화면 캡처 넣기 | 팝업의 **화면 캡처** 탭, 또는 오른쪽 클릭 → **보이는 화면 캡처해서 넣기**. 사진 속 글자는 드라이브 글자 인식으로 같이 적혀요. |
| 이미지 넣기 | 이미지에서 오른쪽 클릭 → **이 이미지 넣기**. 사이트가 내려받기를 막으면 이미지 주소만 남겨요. |
| 링크 넣기 | 링크에서 오른쪽 클릭 → **이 링크 넣기**. 인스타 게시물 주소는 인스타 노트가 돼요. |
| 메모 쓰기 | 팝업의 **메모** 탭. 적다가 팝업이 닫혀도 내용이 남아 있어요. |
| 바로 넣기 | `Alt+Shift+S` 로 지금 페이지를 창 없이 넣어요. |

저장하면 아이콘에 ✓가 잠깐 뜨고, 오른쪽 클릭으로 넣었을 때는 알림이 와요. 알림을 누르면 앱에서 그 노트가 열려요.
단축키는 `chrome://extensions/shortcuts` 에서 바꿀 수 있어요.

## 권한

| 권한 | 쓰는 곳 |
|---|---|
| `identity` | 구글 로그인 창 열기 |
| `activeTab`, `scripting` | 아이콘이나 메뉴를 누른 탭에서만 제목, 주소, 고른 글을 읽고 화면을 캡처해요. 다른 탭이나 방문 기록은 보지 않아요. |
| `contextMenus`, `notifications` | 오른쪽 클릭 메뉴, 저장 알림 |
| `storage` | 연결 상태, 최근에 넣은 노트 5개, 쓰다 만 메모 |
| `googleapis.com` | 구글 드라이브에 저장 (앱이 만든 파일만 보는 `drive.file` 권한) |

로그인 토큰은 브라우저를 닫으면 지워지는 저장소에 두고, 다음에 쓸 때 창 없이 조용히 새로 받아요.

## 업데이트

새 zip을 받아 같은 폴더에 덮어쓴 다음 `chrome://extensions`에서 Thought Drawer의 새로 고침(↻)을 눌러요.

## 개발

`extension/app/` 은 웹앱 코드(`js/config.js`, `js/core/note.js`, `instagram.js`, `compose.js`, `js/store/drive.js`, `auth.js`)의 복사본이에요. 웹앱 쪽을 고쳤으면 아래로 맞추고 zip도 다시 만들어요. `npm test`가 복사본과 zip이 최신인지 확인해요.

```bash
node tools/sync-extension.mjs
```
