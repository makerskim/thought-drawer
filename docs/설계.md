# Thought Drawer 설계

## 목표

메모, 캡처, 웹사이트 북마크, 인스타 저장 게시물을 한곳에 던져 넣으면 Claude가 폴더별로 정리하고 서로 이어 주고,
나중에 검색하거나 문장으로 물어서 다시 찾는다. 폰과 PC에서 같은 내용을 본다.

**제약**: 추가 비용 0원. 유료 API, 유료 서버를 쓰지 않는다. AI는 이미 쓰는 Claude 구독으로만 돌린다.
구독 사용량도 아낀다.

## 구조

```
[아이폰 / PC]  웹앱 (GitHub Pages, 서버 없음)
   │  구글 로그인 (drive.file: 앱이 만든 파일만)
   ▼
[구글 드라이브 「메모」]  유일한 저장소, 마크다운 + 사진
   ▲
   │  하루 2~3번
[Claude Code 예약 작업]  organizer/ (구독으로 실행)
```

| 부분 | 하는 일 | AI 사용 |
|---|---|---|
| 웹앱 `js/` | 노트 넣기와 쓰기, 사진 OCR(드라이브 기본 기능), 찾기, 묻기, 연결과 그래프, 인스타 일괄 가져오기, 내보내기 | 없음 |
| 정리기 `organizer/organize.py prepare` | 인박스 노트 모으기, 링크·인스타 캡션 가져오기, 연결 후보 고르기 | 없음 |
| Claude (예약 작업) | `batch.md`를 읽고 제목·폴더·태그·요약·연결을 `decisions.json`으로 결정 | **여기서만** |
| 정리기 `apply` | 노트 고치기, 폴더로 옮기기, 거꾸로 연결, 색인 만들기 | 없음 |
| 묻기 → "Claude에게 묻기" | 관련 노트 요약을 붙여 claude.ai 새 대화를 연다 | 사용자의 구독 채팅 |

## 노트 형식 (제텔카스텐)

노트 하나 = 마크다운 파일 하나. 옵시디언이 그대로 읽는다.

```markdown
---
id: "20261027093012"
title: "오크우드 가을 시즌오프"
type: "capture"
status: "organized"
category: "패션/쇼핑"
tags: ["세일","오크우드"]
summary: "옥스포드 셔츠 35,400원 시즌오프."
thought: "100 사이즈로 사기"
created: "2026-10-27T09:30:12+09:00"
links: ["20260912214510"]
attachments: ["20261027093012.jpg"]
---

![[20261027093012.jpg]]

## 사진 속 글자

...

## 연결

- [[20260912214510 흰색 옥스포드 셔츠]] (같은 셔츠 할인)
```

| 제텔카스텐 원칙 | Thought Drawer에서 |
|---|---|
| 고유 번호 | `id` = 만든 시각(초). 파일 이름 앞자리 |
| 임시 메모 → 문헌 메모 → 영구 메모 | 인박스 → 출처가 있는 노트(캡처·링크·인스타) → 내 생각이 담긴 메모 |
| 내 말로 다시 쓰기 | 모든 노트의 "내 생각" 칸 |
| 연결과 연결 이유 | `links` + 본문 "## 연결" 목록에 이유를 적고, 상대 노트에도 거꾸로 적는다. 연결 패널의 "비슷한 노트"에서 직접 이을 수도 있다 |
| 한 장에 생각 하나 | 빠른 기록은 하나씩 노트로, 사진은 한 장씩 노트로 |
| 구조 노트 | 폴더(최대 두 단계), 태그, 그래프 |

파일 이름은 처음 정해지면 바꾸지 않는다(링크 보호). 제목 없이 들어온 노트만 첫 정리 때
`번호 제목.md`로 바뀌고, 그때 `[[번호]]`로 걸린 링크도 같이 고친다.

## 사용량 아끼기

- 새 노트가 없으면 Claude가 아무것도 읽지 않고 끝난다.
- 한 번에 최대 30개, 약 14,000자. 남은 건 다음 정리로 넘긴다(최근 것부터).
- 링크 내용, 캡션, 사진 글자는 스크립트가 미리 줄여서 넣는다. 앱이 자동으로 쓴 안내 문장은 뺀다.
- 연결 후보는 낱말이 겹치는 노트 4개만 보여 준다. 전체 목록을 주지 않는다.
- 사진은 글자가 거의 없을 때만 640px로 줄여 보여 준다.
- 권장 모델은 Haiku.

## 구글 연결 이어 가기

`js/store/auth.js` · `js/ui/App.js`

- 서버가 없어서 구글이 주는 열쇠(access token)는 1시간짜리이고, 오래가는 열쇠(refresh token)는 받을 수 없다(받으려면 보안 비밀을 숨길 서버가 필요).
- 그래서 저절로 다시 받는다. 앱을 열 때 만료됐으면 구글로 잠깐 이동(`prompt=none`, `login_hint`)해서 화면 없이 새 열쇠를 받고 보던 화면(`#/...`)으로 돌아온다. 구글 로그인이 풀려 거절되면 10분 동안은 다시 시도하지 않고 「다시 연결」 띠를 보여 준다(되풀이 없음). 인터넷이 없으면 다녀오지 않는다.
- 쓰는 중에는 끝나기 5분 전부터 구글 로그인 스크립트를 미리 받아 두고, 다음 클릭 때 작은 창으로 새로 받는다(이미 허용했으면 누를 것 없이 닫힘). 드라이브 요청은 새로 받는 동안 기다렸다가 보낸다. 아이폰 홈 화면 앱은 창 대신, 앱으로 돌아올 때(적던 글이 없으면) 구글에 잠깐 다녀온다.
- 자동 정리기용 열쇠(refresh token)는 따로 받아 Claude Code 환경에 둔다. 구글 클라우드 동의 화면이 「테스트」면 7일 뒤 끊기니 「프로덕션」으로 둔다(drive.file은 민감하지 않은 권한이라 심사 없이 됨).

## 화면 디자인

애플 홈페이지의 말과 짜임, 넷플릭스의 둘러보기, 옵시디언의 작업 공간을 섞었다. 기능은 네 가지 기준(쉽게 넣기, 어느 기기에서나, 무엇이든 담기, 자동 분류)을 그대로 따른다.

- 위 막대: 52px, 반투명. 왼쪽 ☰(옆 메뉴)와 서랍이·이름, 오른쪽 찾기(빠른 실행)와 내 계정. 넣기 단추는 따로 두지 않는다(첫 화면의 넣는 칸, Enter, 옆 메뉴의 「넣기」).
- 내 계정(오른쪽 위 사진): 구글 계정에 관한 것만, 말은 짧게. 이름·이메일, 연결 상태(끊겼으면 「다시 연결」), 저장 공간 막대(드라이브 API `about.storageQuota`: 전체 · 쓴 양 · 드라이브 / 「메모」 폴더 크기는 파일 목록의 크기 합. 메모 · 드라이브 · Gmail·포토 · 남음, 90% 넘으면 경고), 메모 폴더 열기, 동기화, 구글 계정, 로그아웃(묻고 나서). 넣기·오늘 노트·설정 같은 메뉴는 왼쪽 옆 메뉴에만 둔다.
- 옆 메뉴: ☰로 열면 옆에서 미끄러져 나오고(바깥을 누르거나 Esc로 닫힘), 핀을 누르면 넓은 화면에서 왼쪽이나 오른쪽에 고정된다(⇄로 옮김, 이 기기에 기억). 넣기, 홈, 모든 서랍, 모든 노트·필터, 할 일(남은 수), 오늘 노트, 생각 지도, 즐겨찾기, 서랍 목록(색 점과 수), 넣는 곳(다른 앱·사이트, 북마크, 인스타), 설정, 사용법. 찾기 칸은 두지 않는다(위 막대의 돋보기).
- 첫 화면
  - 첫 화면 높이 가득, 가운데에 큰 제목 「넣기만 하세요. 정리는 서랍이.」, 한 줄 부제 「무엇이든 넣으면 알아서 분류해드립니다.」, 넣는 칸만 둔다(노트는 보이지 않게). 적는 동안 어느 서랍으로 갈지 칸 아래 칩으로. 맨 아래 「내 서랍」.
  - 넣는 칸 왼쪽 +: 사진·스크린샷, 붙여넣기(복사한 링크·글·사진), 북마크 가져오기, 인스타 가져오기, 다른 앱에서 넣기를 목록으로 연다. 넣는 방법은 칸 밖에 늘어놓지 않고 여기에만 둔다.
  - 화면 글은 짧게(이름은 명사, 설명은 한 문장). 서랍이 말풍선만 말하듯.
  - 서랍이: 넣는 칸 위 왼쪽에 앉아 있다(아래쪽은 칸에 가려 고개만 내민 모양). 들어오면 시간에 맞춰 인사, 적으면 글 쪽을 보고 「링크네요! 쇼핑 서랍에 넣을게요」 「요리 서랍이 어울려요」, 넣으면 웃으며 뛰고 「좋아요, 요리 서랍에 넣어 둘게요」, 사진을 끌어 오면 놀라며 「여기 놓으세요!」, 30초 넘게 가만히 있으면 쓰는 법을 하나씩(세 번까지), 누르면 말을 걸고 뛴다. 가끔 눈을 깜빡인다. 다른 곳의 말(`say()`)도 이 말풍선으로 받는다.
  - 아래로 내리면 「내 서랍」 제목과 오늘 줄(날짜, 남은 할 일, 오늘 노트), 이어서 보기, 새로 넣은 것, 서랍마다 한 줄이 차례로 떠오른다.
  - 카드 줄(넷플릭스): 카드는 모두 같은 종이(사진 → 출처 → 제목 → 발췌 → 서랍 점과 날짜), 한 줄 안에서 높이가 같다. PC에서는 줄 양 끝 동그란 화살표로 넘긴다. 「모두 보기 ›」는 서랍 화면으로.
  - 넣는 곳 소개 타일 네 장: 브라우저 단추, 휴대폰 앱, 북마크 가져오기, 생각 지도.
  - 바닥: 작은 링크와 저장 위치 안내.
- 서랍이는 그 밖에: 넣었다는 알림 앞, 노트의 자동 분류 이유(「서랍이가 coupang.com 링크라서 쇼핑 서랍에 넣었어요」), 옆 메뉴 머리(열 때 손 흔듦), 빈 화면, 사용법 안내.
- 서랍 모음: 「서랍.」 큰 제목 아래 서랍마다 타일(서랍 색 아이콘, 노트 수, 자동 분류 수, 세부 서랍별 수, 최근 노트 세 개).
- 서랍 하나·태그·즐겨찾기·찾기: 두 번째 막대(애플 제품 페이지의 로컬 막대: 뒤로, 이름, 보기 메뉴), 「쇼핑.」 큰 제목과 노트 수(걸렀으면 「N개 / 전체 N개」), 자동 분류 안내, 세부 서랍 칩, 필터 막대, 카드 판(또는 목록에서 여러 개 골라 옮기기·지우기). 카드 바닥에 「서랍 › 세부 서랍」.
- 설정: 위에 목차 칩(계정, 화면, 넣기, 자동 분류, 분류 규칙, / 명령어, Claude, 공유·내보내기, 단축키). 켜고 끄는 값은 스위치, 고르는 값은 분할 단추. 분류 규칙에는 「시험해 보기」 칸.
- 사용법(`#/help`): 넣기, / 명령어(내 키워드 포함 표), # 태그·@ 서랍, 자동 분류(기본 서랍 펼쳐 보기), 필터, 노트 편집기, 단축키, 다른 앱에서 넣기 카드. 화면 안내 다시 보기 단추.
- 노트(옵시디언 작업 공간): 세 칸. 왼쪽은 같은 서랍의 노트 목록(지금 노트 표시), 가운데는 위 막대(닫기, 이전·다음, 서랍 › 제목, 저장 상태, 즐겨찾기, 더 보기)와 큰 제목, 속성 표(서랍과 자동 분류 이유, 태그, 종류, 출처, 만든 날), Claude 요약 콜아웃, 내 생각, 템플릿, 편집기. 오른쪽은 연결(이어진 · 언급한 · 비슷한 노트) · 목차 · 로컬 그래프 탭. 좁은 화면에서는 왼쪽부터 접고, 폰은 한 칸으로 아래에 이어 붙인다. `J`/`K`는 보던 목록(없으면 같은 서랍) 순서로 넘긴다. `Esc`는 보던 화면으로.
- 빠른 실행(애플 검색 + 옵시디언 명령 팔레트): `/` 또는 `Ctrl/⌘ K`. 적는 대로 노트를 찾고, 할 일 이름(오늘 노트, 설정, 북마크 가져오기…)과 맞으면 그 명령을 먼저 보여 준다. 「모두 찾아보기」와 「Claude에게 물어보기」.
- 색과 글: [디자인시스템.md](디자인시스템.md)의 규칙을 따른다. 중립 회색 + 애플 파랑 하나, 카드는 모두 같은 종이, 서랍은 작은 색 점으로만. 밝기는 기기를 따르고 설정에서 낮·밤 고정. 글꼴은 Pretendard.

## 자동 분류

`js/core/classify.js` (기기 안에서, 넣는 즉시. 서버·AI 요청 없음)

- 서랍을 먼저 고르고, 그 안에서 같은 방법으로 세부 서랍을 고른다. 1.2점이 안 되면 서랍은 「기타」, 세부 서랍은 비워 둔다.
  1. 내 분류 규칙(설정): 낱말이나 사이트가 나오면 10점, 정한 세부 서랍과 태그를 그대로 쓴다.
  2. 사이트: 서랍·세부 서랍마다 알려진 주소(쿠팡 → 쇼핑, 다나와 → 쇼핑 › 가전, 아고다 → 여행 › 숙소…). 맞으면 4점. 링크 노트가 아니어도 글 속 첫 주소를 본다.
  3. 낱말: 서랍·세부 서랍마다 낱말 목록. 맞은 낱말 하나에 1.2점, 4개까지. 영어는 낱말 단위(ai가 mail에 걸리지 않게), 한 글자 한글(책·쌀·찜)은 다른 낱말 속(책임·책상)에 걸리지 않게 앞뒤를 본다.
  4. 배운 것: 내가(또는 Claude가) 서랍을 정한 노트에서 서랍·세부 서랍마다 자주 나오는 낱말과 사이트를 세어 두고 비교한다. 노트가 적은 서랍은 덜 믿는다.
- 기본 서랍 10개와 세부 서랍 45개: 쇼핑(가전, 생활용품, 식품, 선물, 위시리스트), 패션·뷰티(옷, 신발·가방, 뷰티, 액세서리), 요리·맛집(레시피, 맛집, 카페, 배달), 여행(국내, 해외, 숙소, 교통, 캠핑), 공부·자료(책, 강의, 외국어, IT, 아티클), 일·업무(회의, 프로젝트, 커리어, 도구), 영상·음악(영상, 영화·드라마, 음악, 공연·전시), 건강·운동(운동, 식단, 병원, 마음), 돈·재테크(투자, 저축·대출, 세금·보험, 부동산, 가계부), 집·생활(인테리어, 살림, 반려동물, 육아, 이사). 이미 「패션/상의」 같은 폴더가 있으면 그 이름을 쓴다(별칭으로 맞춤).
- 자동 태그(기본 4개, 설정에서 0~8): 규칙의 태그 → 이미 쓰는 태그 중 글에 나온 것 → 사이트 이름(#쿠팡) → 세부 서랍 낱말 → 서랍 낱말 → 다른 서랍 낱말. 낱말 조각(「사고 싶」)은 태그로 쓰지 않고, 「항공권」이 있으면 「항공」은 뺀다. 새 노트는 넣을 때 태그를 파일에 써 두고(옵시디언에서도 보임), 태그가 없는 예전 노트는 화면에서만 자동 태그로 보인다(노트에서 「태그로 저장」).
- 파일은 옮기지 않는다. 서랍이 정해지지 않은 노트(인박스)는 화면에서만 자동 서랍에 보이고, 노트에서 서랍을 고르거나 `@서랍`으로 넣으면 그때 그 폴더로 옮긴다(이후 학습 자료가 된다). 그래서 드라이브가 잠깐 안 돼도 분류는 늘 보이고, 선택으로 켜는 Claude 정리기와도 부딪히지 않는다(정리기는 인박스 노트를 다듬어 폴더로 옮기고, 내 분류 규칙을 batch.md에 받아 그대로 따른다).
- 북마크 가져오기는 북마크 폴더 이름(의미 없는 「북마크바」 등은 뺌)을 태그로 붙이고, 원래 저장한 날짜를 쓴다.

## 필터

`js/core/filter.js` · `js/ui/parts/filters.js`

- 모든 노트·서랍·태그·즐겨찾기·찾기 화면 위의 막대: 날짜 · 종류 · 서랍(› 세부 서랍) · 태그(여러 개, 모두 가진 노트) · 사이트 · 조건, 그리고 보기 메뉴의 정렬(최근 넣은 순, 오래된 순, 최근 고친 순, 이름 순).
- 날짜: 오늘, 어제, 이번 주(월요일부터), 최근 7일, 이번 달, 최근 30일, 올해, 기간 지정. 기준은 넣은 날 또는 고친 날. 날짜가 없으면 노트 번호(만든 시각)로.
- 조건: 할 일 있음, 남은 할 일, 할 일 다 함, 사진 있음, 요약 있음, 즐겨찾기, 직접 정한 서랍, 자동 분류만, 태그 없음. 할 일 조건을 고르면 본문을 아직 안 받은 노트를 받아 온다.
- 고른 값은 주소(`#/all?d=week&dr=쇼핑/가전&tag=세일`)에 담긴다. 뒤로 가기에는 쌓지 않는다.

## / 명령어와 함께 쓰는 설정

`js/core/slash.js` · `js/ui/parts/slash.js` · `js/core/settings.js`

- 입력칸(첫 화면, 가운데 입력창)에서 줄 처음이나 띄어쓰기 뒤의 `/` → 명령어와 내 키워드(+ 이름이 맞는 서랍), `#` → 쓰던 태그(없으면 새 태그), `@` → 서랍(기본·세부·이미 있는 폴더, 없으면 새 서랍). ↑↓, Enter·Tab, Esc. 주소 안의 `/`·`#`, 이메일의 `@`는 걸리지 않는다.
- 기본 명령어: 할일, 오늘, 내일, 어제, 지금, 태그, 서랍, 사진, 붙여넣기, 크게. 노트 편집기의 `/` 메뉴는 블록(제목, 목록, 할 일, 인용, 코드, 구분선, 사진, 잇기) + 날짜·시각 + 내 키워드.
- 넣을 때 `#태그`는 태그로, 아는 서랍의 `@서랍`은 그 폴더로(직접 정한 서랍) 보내고 글에서는 뺀다. 아이폰 공유·사진 메모에도 같다. 모르는 `@이름`(인스타 계정 등)은 그대로 둔다.
- 내 키워드·분류 규칙·자동 분류 설정은 드라이브 `메모/_시스템/settings.json`에 저장해 기기 사이에 함께 쓴다. 밝기, 글꼴, 옆 메뉴, 서랍이 말풍선, 넣고 바로 열기, 첫 줄 제목은 이 기기에만(브라우저 저장).

## 일부러 뺀 것

- 유튜브 정리, 영상 내용(음성·장면) 분석: 사용량이 많이 든다.
- 인스타 아이디·비밀번호 자동 로그인: 약관 위반, 계정 정지 위험. 대신 인스타 공식 "내 정보 다운로드" 파일을 쓴다.
- 앱 안에서 바로 AI 답변: 구독을 웹앱에서 직접 쓸 수 없다. 대신 관련 노트를 붙여 Claude 앱으로 넘긴다.
