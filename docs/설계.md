# 생각서랍 설계

## 목표

메모, 캡처, 웹사이트 북마크, 인스타 저장 게시물을 한곳에 던져 넣으면 Claude가 서랍(폴더)별로 정리하고,
나중에 검색하거나 문장으로 물어서 다시 찾는다. 폰과 PC에서 같은 내용을 본다.

**제약**: 추가 비용 0원. 유료 API, 유료 서버를 쓰지 않는다. AI는 이미 쓰는 Claude 구독으로만 돌린다.
구독 사용량도 아낀다.

## 구조

```
[아이폰 / PC]  웹앱 (GitHub Pages, 서버 없음)
   │  구글 로그인 (drive.file: 앱이 만든 파일만)
   ▼
[구글 드라이브 「메모」]  유일한 저장소, 마크다운 + 사진
   ▲
   │  하루 2~3번
[Claude Code 예약 작업]  organizer/ (구독으로 실행)
```

| 부분 | 하는 일 | AI 사용 |
|---|---|---|
| 웹앱 `js/` | 카드 넣기, 사진 OCR(드라이브 기본 기능), 보기, 찾기, 묻기, 연결 지도, 인스타 일괄 가져오기, 내보내기 | 없음 |
| 정리기 `organizer/organize.py prepare` | 인박스 카드 모으기, 링크·인스타 캡션 가져오기, 연결 후보 고르기 | 없음 |
| Claude (예약 작업) | `batch.md`를 읽고 제목·서랍·태그·요약·연결을 `decisions.json`으로 결정 | **여기서만** |
| 정리기 `apply` | 카드 고치기, 서랍으로 옮기기, 거꾸로 연결, 색인 만들기 | 없음 |
| 묻기 → "Claude에게 더 묻기" | 관련 카드 요약을 붙여 claude.ai 새 대화를 연다 | 사용자의 구독 채팅 |

## 카드 형식 (제텔카스텐)

카드 한 장 = 마크다운 파일 하나. 옵시디언이 그대로 읽는다.

```markdown
---
id: "20261027093012"
title: "오크우드 가을 시즌오프"
type: "capture"
status: "organized"
category: "패션/쇼핑"
tags: ["세일","오크우드"]
summary: "옥스포드 셔츠 35,400원 시즌오프."
thought: "100 사이즈로 사기"
created: "2026-10-27T09:30:12+09:00"
links: ["20260912214510"]
attachments: ["20261027093012.jpg"]
---

![[20261027093012.jpg]]

## 사진 속 글자

...

## 연결

- [[20260912214510 흰색 옥스포드 셔츠]] (같은 셔츠 할인)
```

| 제텔카스텐 원칙 | 생각서랍에서 |
|---|---|
| 고유 번호 | `id` = 만든 시각(초). 파일 이름 앞자리. 카드에 타자기 글씨로 찍힘 |
| 임시 메모 → 문헌 메모 → 영구 메모 | 정리 대기(인박스) → 출처가 있는 카드(캡처·북마크·인스타) → 내 생각이 담긴 메모 |
| 내 말로 다시 쓰기 | 모든 카드의 "내 생각 한 줄" 칸 |
| 연결과 연결 이유 | `links` + 본문 "## 연결" 목록에 이유를 적고, 상대 카드에도 거꾸로 적는다 |
| 한 장에 생각 하나 | 메모 입력 안내 문구, 사진은 한 장씩 카드로 |
| 구조 노트 | 서랍(최대 두 단계)과 연결 지도 |

파일 이름은 처음 정해지면 바꾸지 않는다(링크 보호). 제목 없이 들어온 카드만 첫 정리 때
`번호 제목.md`로 바뀌고, 그때 `[[번호]]`로 걸린 링크도 같이 고친다.

## 사용량 아끼기

- 새 카드가 없으면 Claude가 아무것도 읽지 않고 끝난다.
- 한 번에 최대 30장, 약 14,000자. 남은 건 다음 정리로 넘긴다(최근 것부터).
- 링크 내용, 캡션, 사진 글자는 스크립트가 미리 줄여서 넣는다. 앱이 자동으로 쓴 안내 문장은 뺀다.
- 연결 후보는 낱말이 겹치는 카드 4장만 보여 준다. 전체 목록을 주지 않는다.
- 사진은 글자가 거의 없을 때만 640px로 줄여 보여 준다.
- 권장 모델은 Haiku.

## 화면 디자인

도서관 카드 목록함. 서랍 앞판에 놋쇠 이름표와 손잡이, 카드에는 빨간 머리줄과 파란 괘선,
카드 번호는 타자기 글씨. 글꼴은 Hahmlet(제목), IBM Plex Sans KR(본문), Courier Prime(번호).
밝은 화면은 철제 캐비닛의 연한 세이지, 어두운 화면은 블루블랙 잉크색.

## 일부러 뺀 것

- 유튜브 정리, 영상 내용(음성·장면) 분석: 사용량이 많이 든다.
- 인스타 아이디·비밀번호 자동 로그인: 약관 위반, 계정 정지 위험. 대신 인스타 공식 "내 정보 다운로드" 파일을 쓴다.
- 앱 안에서 바로 AI 답변: 구독을 웹앱에서 직접 쓸 수 없다. 대신 관련 카드를 붙여 Claude 앱으로 넘긴다.
