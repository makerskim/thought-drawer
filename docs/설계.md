# Thought Drawer 설계

## 목표

메모, 캡처, 웹사이트 북마크, 인스타 저장 게시물을 한곳에 던져 넣으면 Claude가 폴더별로 정리하고 서로 이어 주고,
나중에 검색하거나 문장으로 물어서 다시 찾는다. 폰과 PC에서 같은 내용을 본다.

**제약**: 추가 비용 0원. 유료 API, 유료 서버를 쓰지 않는다. AI는 이미 쓰는 Claude 구독으로만 돌린다.
구독 사용량도 아낀다.

## 구조

```
[아이폰 / PC]  웹앱 (GitHub Pages, 서버 없음)
   │  구글 로그인 (drive.file: 앱이 만든 파일만)
   ▼
[구글 드라이브 「메모」]  유일한 저장소, 마크다운 + 사진
   ▲
   │  하루 2~3번
[Claude Code 예약 작업]  organizer/ (구독으로 실행)
```

| 부분 | 하는 일 | AI 사용 |
|---|---|---|
| 웹앱 `js/` | 노트 넣기와 쓰기, 사진 OCR(드라이브 기본 기능), 찾기, 묻기, 연결과 그래프, 인스타 일괄 가져오기, 내보내기 | 없음 |
| 정리기 `organizer/organize.py prepare` | 인박스 노트 모으기, 링크·인스타 캡션 가져오기, 연결 후보 고르기 | 없음 |
| Claude (예약 작업) | `batch.md`를 읽고 제목·폴더·태그·요약·연결을 `decisions.json`으로 결정 | **여기서만** |
| 정리기 `apply` | 노트 고치기, 폴더로 옮기기, 거꾸로 연결, 색인 만들기 | 없음 |
| 묻기 → "Claude에게 묻기" | 관련 노트 요약을 붙여 claude.ai 새 대화를 연다 | 사용자의 구독 채팅 |

## 노트 형식 (제텔카스텐)

노트 하나 = 마크다운 파일 하나. 옵시디언이 그대로 읽는다.

```markdown
---
id: "20261027093012"
title: "오크우드 가을 시즌오프"
type: "capture"
status: "organized"
category: "패션/쇼핑"
tags: ["세일","오크우드"]
summary: "옥스포드 셔츠 35,400원 시즌오프."
thought: "100 사이즈로 사기"
created: "2026-10-27T09:30:12+09:00"
links: ["20260912214510"]
attachments: ["20261027093012.jpg"]
---

![[20261027093012.jpg]]

## 사진 속 글자

...

## 연결

- [[20260912214510 흰색 옥스포드 셔츠]] (같은 셔츠 할인)
```

| 제텔카스텐 원칙 | Thought Drawer에서 |
|---|---|
| 고유 번호 | `id` = 만든 시각(초). 파일 이름 앞자리 |
| 임시 메모 → 문헌 메모 → 영구 메모 | 인박스 → 출처가 있는 노트(캡처·링크·인스타) → 내 생각이 담긴 메모 |
| 내 말로 다시 쓰기 | 모든 노트의 "내 생각" 칸 |
| 연결과 연결 이유 | `links` + 본문 "## 연결" 목록에 이유를 적고, 상대 노트에도 거꾸로 적는다. 연결 패널의 "비슷한 노트"에서 직접 이을 수도 있다 |
| 한 장에 생각 하나 | 빠른 기록은 하나씩 노트로, 사진은 한 장씩 노트로 |
| 구조 노트 | 폴더(최대 두 단계), 태그, 그래프 |

파일 이름은 처음 정해지면 바꾸지 않는다(링크 보호). 제목 없이 들어온 노트만 첫 정리 때
`번호 제목.md`로 바뀌고, 그때 `[[번호]]`로 걸린 링크도 같이 고친다.

## 사용량 아끼기

- 새 노트가 없으면 Claude가 아무것도 읽지 않고 끝난다.
- 한 번에 최대 30개, 약 14,000자. 남은 건 다음 정리로 넘긴다(최근 것부터).
- 링크 내용, 캡션, 사진 글자는 스크립트가 미리 줄여서 넣는다. 앱이 자동으로 쓴 안내 문장은 뺀다.
- 연결 후보는 낱말이 겹치는 노트 4개만 보여 준다. 전체 목록을 주지 않는다.
- 사진은 글자가 거의 없을 때만 640px로 줄여 보여 준다.
- 권장 모델은 Haiku.

## 화면 디자인

페이지와 폴더 나무를 관리하는 노션식 구조가 아니라, 넣고 다시 찾는 일 하나에 맞춘 한 화면이다.

- 넣기: 어디서든 Enter를 누르거나 「생각 넣기」를 누르면 화면 가운데에 입력창이 뜨고, 서랍이가 창 위로 고개를 내민다. 적고 Enter면 인박스에 넣고(알림의 되돌리기로 바로 취소), Shift+Enter는 줄바꿈. 주소로 시작하면 링크, 여러 줄이면 첫 줄이 제목이라는 걸 입력창 아래 한 줄로 미리 알려 준다. 사진은 붙여 넣거나 끌어다 놓는다. 넣지 않고 닫으면 다음에 열 때 이어 쓴다. 폰에서는 「생각 넣기」 단추가 화면 아래 가운데(엄지가 닿는 곳)에 떠 있다.
- 찾기 칸: 입력하는 대로 아래 노트가 걸러지고, ↓나 Enter로 결과로 간다. 「물어보기」(Ctrl/⌘ Enter)는 Claude에게 묻는다. `/`나 `Ctrl/⌘ K`로 어디서든 이 칸으로 간다.
- 칸 아래 칩: 전체, 인박스(정리 대기 수), ★ 즐겨찾기, 폴더들. 폴더를 고르면 안쪽 폴더 칩이 한 줄 더 나온다. 오른쪽에는 종류(사진, 링크, 인스타, 메모)와 보기(벽, 목록).
- 노트 벽: 사진이 있으면 사진이 앞에 나오는 카드. 목록으로 바꾸면 여러 개 골라 옮기거나 지우고, 줄마다 바로 폴더를 정한다.
- 노트는 옆 창에서 열린다(폰은 화면 가득). 벽은 그대로라 다른 카드를 누르거나 `J`/`K`로 다음·이전 노트로 넘어가고, `Esc`로 닫는다. 큰 제목, 그 아래 한 줄(폴더, #태그, 출처, 종류, 날짜), Claude 요약과 내 생각, 보이는 그대로 편집하는 본문, 맨 아래 이어진 노트와 비슷한 노트(한 번에 잇기).
- 묻기도 옆 창: 찾기 칸에 적고 「물어보기」를 누르면 관련 노트를 폴더별로 모아 보여 준다.
- 그래프, 폰과 크롬에서 쓰기, 인스타 가져오기, 설정은 오른쪽 위 동그란 메뉴에서 연다.
- 사진은 어디서든 붙여 넣거나 끌어다 놓으면 인박스에 들어간다. 지우면 되돌리기 알림이 뜬다.
- 시작할 때 기기에 저장해 둔 사본을 먼저 보여 주고, 드라이브와는 뒤에서 맞춘다. 연결이 끊겨도 읽을 수 있다.
- 사용법 안내: 처음 열면 화면을 어둡게 덮고 넣기 단추, 찾기 칸, 칩, 카드, 메뉴를 차례로 밝히며 설명한다. 「넘기기」, 「이전」, 「확인」(키보드는 Enter, ←/→, Esc). 한 번 보면 이 기기에서는 다시 뜨지 않고, 메뉴의 「사용법 다시 보기」로 언제든 본다.
- 빈자리 채우기: 노트 위에 「서랍은 이렇게 돌아가요」(넣기 → Claude가 정리 → 찾고 묻기) 띠, 노트가 12개보다 적으면 벽 끝에 쓰는 법 카드(메모, 링크, 캡처, 인스타, 폰과 크롬, 물어보기). 카드를 누르면 바로 그걸 하게 된다. 띠를 닫으면 둘 다 숨는다. 서랍이 비어 있으면 서랍이가 손을 흔들며 첫 생각 넣기를 권한다.
- 분위기는 책상 서랍: 모눈 종이 위 흰 카드, 누르는 단추는 볼펜 파랑, 고른 상태는 먹색, 메모와 즐겨찾기는 포스트잇 노랑. 종류는 이모지 대신 색 있는 선 아이콘, 폴더는 색 점으로 구분한다. 마스코트 서랍이(두 칸짜리 파란 서랍장, 위 서랍에 눈, 아래 서랍 손잡이가 입, 머리에 쪽지)가 입력창, 안내, 빈 화면에 나온다. 글은 Wanted Sans, 이름과 큰 제목은 나눔스퀘어라운드 ExtraBold. 색은 설정에서 파랑·민트·귤·포도 중에 고르고(서랍이 색도 같이 바뀐다), 낮/밤 테마가 있다. 노트 글꼴은 기본·동글·명조·고정폭 중에서.

## 일부러 뺀 것

- 유튜브 정리, 영상 내용(음성·장면) 분석: 사용량이 많이 든다.
- 인스타 아이디·비밀번호 자동 로그인: 약관 위반, 계정 정지 위험. 대신 인스타 공식 "내 정보 다운로드" 파일을 쓴다.
- 앱 안에서 바로 AI 답변: 구독을 웹앱에서 직접 쓸 수 없다. 대신 관련 노트를 붙여 Claude 앱으로 넘긴다.
